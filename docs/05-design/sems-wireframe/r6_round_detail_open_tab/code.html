ยืนยันการปิดรอบทุนการศึกษา

คุณต้องการปรับเปลี่ยนสถานะของรอบทุน "ทุนการศึกษาเรียนดี" เป็น "ปิดการประเมิน (Closed)" หรือไม่?

• ผลกระทบเมื่อปิดรอบทุน:

1. ระบบจะยุติการเปิดรับใบสมัครจากนักศึกษาทันที

2. คณะกรรมการประเมินจะสามารถเริ่มลงคะแนนในหน้าผลการประเมินได้

3. การดำเนินการนี้ไม่สามารถย้อนกลับเป็นสถานะ Open ได้
