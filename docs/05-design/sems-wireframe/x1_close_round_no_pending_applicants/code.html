ปิดรอบทุนการศึกษา?

ยืนยันการสิ้นสุดขั้นตอนการให้คะแนนและปิดรับการประเมิน

ผู้สมัครทุกรายมีผลการประเมิน Submitted แล้ว เมื่อปิดรอบจะไม่สามารถแก้ไขหรือยืนยันส่งผลการประเมินได้ และไม่สามารถย้อนสถานะ

  • • ผู้สมัครทั้งหมด 8 รายได้รับการประเมินครบถ้วน 100%
  • • ระบบจะทำการประมวลผลคะแนนสุดท้าย (Final Score) และจัดอันดับเพื่อเตรียมจัดสรรทุน
  • • สถานะรอบทุนจะเปลี่ยนเป็น Closed และล็อกการแก้ไขถาวร
