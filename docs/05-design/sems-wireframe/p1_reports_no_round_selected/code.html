เลือกรอบทุนเพื่อส่งออกรายงาน

กรุณาเลือกรอบทุนการศึกษาจากรายการด้านบน เพื่อดูและส่งออกรายงานที่เกี่ยวข้อง

info คำแนะนำการทำงาน (WORKFLOW GUIDELINES)
  1. เลือก รอบทุนการศึกษา จากตัวเลือกตัวกรองด้านบน
  2. ระบบจะดึงชุดข้อมูลผลการประเมิน รายชื่อผู้สมัคร และงบประมาณโดยอัตโนมัติ
  3. สามารถเลือกดาวน์โหลดแบบสรุปรายบุคคล สรุปรายหมวดหมู่ หรือเอกสารส่งออกทางการ (PDF/XLSX)
