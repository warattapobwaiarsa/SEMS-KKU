เลือกรอบทุนเพื่อดูรายชื่อผู้สมัคร

กรุณาเลือกรอบทุนการศึกษาจากเมนูด้านบน เพื่อตรวจสอบรายชื่อผู้สมัคร นำเข้าข้อมูล หรือจัดการข้อมูลการสมัครของแต่ละรอบทุน

checklist คู่มือขั้นตอนการดำเนินงาน (Workflow Guide)
1
เลือกรอบทุนที่ต้องการจัดการ เลือกรอบทุนการศึกษาที่เปิดใช้งานจากกล่องเมนูดรอปดาวน์ด้านบน
2
หากเป็นรอบสถานะ Draft สามารถนำเข้าข้อมูลไฟล์ Excel ได้ สามารถอัปโหลดรายชื่อ ข้อมูลเกรดเฉลี่ย รายได้ และคุณสมบัติของนักศึกษาแบบเป็นกลุ่มผ่านไฟล์แม่แบบ (.xlsx, .csv)
3
หากเป็นรอบสถานะ Open หรือ Closed ข้อมูลจะแสดงเพื่อการตรวจสอบเท่านั้น ระบบจะล็อกการนำเข้าไฟล์เพิ่มเติมเพื่อความปลอดภัยของข้อมูล และแสดงสถานะการสมัคร การส่งเอกสาร พร้อมคะแนนประเมินรายบุคคล
