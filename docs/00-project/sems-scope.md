# 1.3 ขอบเขตโครงงาน

## 1.3.1 ภาพรวมระบบ

ระบบบริหารจัดการการประเมินทุนการศึกษา (Scholarship Evaluation Management System: SEMS) เป็นระบบที่มีการทำงานทั้งส่วน Frontend และ Backend ในรูปแบบเว็บแอปพลิเคชัน ซึ่งสามารถใช้งานผ่าน Web Browser บนเครื่องคอมพิวเตอร์ และรองรับการใช้งานผ่าน Web Browser บนโทรศัพท์มือถือและแท็บเล็ตด้วยการแสดงผลแบบ Responsive  
 โดยระบบแบ่งกลุ่มผู้ใช้ออกเป็น 2 กลุ่ม คือ กลุ่มผู้ดูแลระบบ (Admin) ซึ่งเป็นผู้จัดการข้อมูลและกระบวนการของรอบทุนการศึกษา และกลุ่มผู้ประเมิน (Evaluator) ซึ่งเป็นผู้ประเมินผู้สมัครทุนการศึกษา โดยมีฟังก์ชันการทำงานต่อไปนี้

### 1.3.1.1 ฟังก์ชันสำหรับผู้ดูแลระบบ

1. ผู้ดูแลระบบสามารถเข้าสู่ระบบและออกจากระบบได้  
2. ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลผู้ใช้งานและสถานะการใช้งานบัญชี รวมถึงกำหนดอายุการใช้งานบัญชีผู้ประเมินได้  
3. ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลรอบทุนการศึกษาได้  
4. ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลเกณฑ์การประเมินและเกณฑ์ย่อย รวมถึงเชื่อมโยงเกณฑ์การประเมินกับรอบทุนการศึกษาได้  
5. ผู้ดูแลระบบสามารถนำเข้าข้อมูลผู้สมัครทุนการศึกษาผ่านไฟล์ Excel ได้  
6. ผู้ดูแลระบบสามารถ ค้นหา และดูรายชื่อผู้สมัครในรอบทุนการศึกษาได้  
7. ผู้ดูแลระบบสามารถเปิดและปิดรอบทุนการศึกษาได้  
8. ผู้ดูแลระบบสามารถ ค้นหา ข้อมูลผลการประเมินและอันดับของผู้สมัครได้  
9. ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลผลการจัดสรรทุนการศึกษาได้ รวมถึงกำหนดงบประมาณรวมของรอบทุน  
10. ผู้ดูแลระบบสามารถยืนยันผลการจัดสรรทุนการศึกษาและเปิดผลการจัดสรรที่ยืนยันแล้วกลับมาแก้ไขได้  
11. ผู้ดูแลระบบสามารถ ค้นหา และส่งออกรายงานสรุปผลการประเมินและอันดับในรูปแบบไฟล์ Excel ได้  
12. ผู้ดูแลระบบสามารถ ค้นหา และส่งออกรายงานผลการจัดสรรทุนการศึกษาในรูปแบบไฟล์ Excel ได้  
13. ผู้ดูแลระบบสามารถ ค้นหา และดูประวัติการสมัครทุนการศึกษาของนักศึกษาข้ามรอบทุนได้  
14. ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลประเภททุนการศึกษา รวมถึงกำหนดเกณฑ์การประเมินเริ่มต้นของแต่ละประเภทได้  
15. ผู้ดูแลระบบสามารถดูหน้าสรุปข้อมูลวิเคราะห์ของรอบทุนการศึกษาได้

### 1.3.1.2 ฟังก์ชันสำหรับผู้ประเมิน

1. ผู้ประเมินสามารถเข้าสู่ระบบและออกจากระบบได้  
2. ผู้ประเมินสามารถ ค้นหา และเลือกผู้สมัครทุนการศึกษาที่เปิดให้ประเมินได้  
3. ผู้ประเมินสามารถดูรายละเอียดข้อมูลผู้สมัคร ข้อมูลประกอบการพิจารณา และประวัติการสมัครและการได้รับทุนของผู้สมัครในระบบ SEMS ได้  
4. ผู้ประเมินสามารถ กรอก แก้ไข คะแนนในแต่ละเกณฑ์ย่อยแบบมีคะแนน บันทึกความคิดเห็นในเกณฑ์ย่อยที่อนุญาตให้ความคิดเห็น รวมถึงกรอกข้อมูลในเกณฑ์ย่อยแบบไม่มีคะแนน (ถ้ามี) ในสถานะ Draft ได้  
5. ผู้ประเมินสามารถตรวจสอบสรุปผลการประเมินก่อนยืนยันส่งผลได้  
6. ผู้ประเมินสามารถยืนยันส่งผลการประเมินได้

### 1.3.1.3 ฟังก์ชันการทำงานของระบบ

1. ระบบสามารถยืนยันตัวตนผู้ใช้งานและตรวจสอบสิทธิ์การเข้าถึงตามบทบาทได้  
2. ระบบสามารถตรวจสอบความพร้อมของรอบทุนก่อนอนุญาตให้เปิดรอบได้  
3. ระบบสามารถอ่านและตรวจสอบข้อมูลจากไฟล์ Excel ก่อนนำเข้าข้อมูลผู้สมัครได้  
4. ระบบสามารถ คำนวณ และจัดอันดับคะแนนของผู้สมัครจากผลการประเมินที่มีสถานะ Submitted ได้  
5. ระบบสามารถตรวจสอบและแสดงผู้สมัครที่ยังไม่มีผลการประเมินก่อนปิดรอบทุนการศึกษาได้  
6. ระบบสามารถตรวจสอบงบประมาณและผลการจัดสรรทุนการศึกษาได้  
7. ระบบสามารถจัดการสถานะผลการจัดสรรทุนการศึกษาได้  
8. ระบบสามารถค้นหาและส่งออกรายงานสรุปผลการประเมินในรูปแบบไฟล์ Excel ได้  
9. ระบบสามารถค้นหาและส่งออกรายงานผลการจัดสรรทุนการศึกษาในรูปแบบไฟล์ Excel ได้  
10. ระบบสามารถคุ้มครองข้อมูลส่วนบุคคลได้  
11. ระบบสามารถประมวลผลข้อมูลสรุปสำหรับหน้าวิเคราะห์ข้อมูลได้

## 1.3.2 กลุ่มผู้ดูแลระบบ (Admin) สามารถใช้งานผ่านเว็บแอปพลิเคชัน โดยมีฟังก์ชันดังนี้

### 1.3.2.1 ผู้ดูแลระบบสามารถเข้าสู่ระบบและออกจากระบบได้

โดยเข้าสู่ระบบด้วย KKU Single Sign-On (KKU SSO) ที่ได้รับการกำหนดสิทธิ์และอยู่ในสถานะเปิดการใช้งานเท่านั้น และสามารถออกจากระบบเพื่อสิ้นสุดการใช้งานได้ ซึ่งข้อมูลประกอบด้วย

* บัญชีผู้ใช้งาน  
* บทบาทผู้ใช้งาน  
* สถานะการใช้งานบัญชี

### 1.3.2.2 ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลผู้ใช้งานและสถานะการใช้งานบัญชีได้

โดยผู้ดูแลระบบสามารถเพิ่มผู้ใช้งาน กำหนดบทบาทเป็น Admin หรือ Evaluator แก้ไขข้อมูลผู้ใช้งาน เปิดหรือปิดสถานะการใช้งานบัญชี และค้นหาโดยใช้ชื่อผู้ใช้งาน บัญชีผู้ใช้งาน บทบาท หรือสถานะการใช้งานบัญชี

ในการเพิ่มผู้ใช้งานที่มีบทบาทเป็น Evaluator ผู้ดูแลระบบต้องกำหนดอายุการใช้งานบัญชีเป็นจำนวนวัน ระบบจะคำนวณวันหมดอายุของบัญชีและเปลี่ยนสถานะบัญชีเป็นปิดการใช้งานโดยอัตโนมัติเมื่อถึงวันหมดอายุ เพื่อลดภาระของผู้ดูแลระบบ และผู้ดูแลระบบสามารถต่ออายุการใช้งานบัญชีได้ เมื่อเปิดใช้งานบัญชีผู้ประเมินที่ถูกปิดไปแล้วกลับมา ผู้ดูแลระบบต้องกำหนดวันหมดอายุใหม่ทุกครั้ง ส่วนบัญชีที่มีบทบาทเป็น Admin ไม่มีวันหมดอายุ

เพื่อป้องกันปัญหาผลการประเมินค้างในสถานะ Draft ระบบไม่อนุญาตให้ผู้ดูแลระบบปิดการใช้งานบัญชีผู้ประเมินที่ยังมีผลการประเมินสถานะ Draft ในรอบทุนที่อยู่ในสถานะ Open และหากถึงวันหมดอายุของบัญชีในขณะที่ยังมีผลการประเมินสถานะ Draft ดังกล่าว ระบบจะเลื่อนการปิดบัญชีอัตโนมัติออกไปจนกว่าผู้ประเมินจะยืนยันส่งผล หรือรอบทุนนั้นเปลี่ยนเป็นสถานะ Closed ทั้งนี้ บัญชีผู้ประเมินที่พ้นวันหมดอายุแต่ยังเปิดใช้งานอยู่เพราะมีผลการประเมินสถานะ Draft ค้างอยู่ สามารถแก้ไขและยืนยันส่งผลได้เฉพาะผลการประเมิน Draft เดิมเท่านั้น และไม่สามารถเริ่มประเมินผู้สมัครรายใหม่ได้ เพื่อไม่ให้การเลื่อนการปิดบัญชีต่อเนื่องไม่สิ้นสุด และบัญชีที่ถูกปิดการใช้งานจะไม่สามารถเข้าสู่ระบบเพื่อประเมินได้ และผู้ดูแลระบบไม่สามารถยืนยันส่งผลการประเมินแทนผู้ประเมินได้ ระบบไม่รองรับการลบบัญชีผู้ใช้งาน สามารถปิดการใช้งานบัญชีได้เท่านั้น ซึ่งข้อมูลประกอบด้วย

* รหัสผู้ใช้งาน  
* บัญชีผู้ใช้งาน  
* ชื่อผู้ใช้งาน  
* บทบาทผู้ใช้งาน (1 \= Admin, 2 \= Evaluator)  
* สถานะการใช้งานบัญชี (0 \= ปิดการใช้งาน, 1 \= เปิดการใช้งาน)  
* วันหมดอายุของบัญชี (เฉพาะบทบาท Evaluator)

### 1.3.2.3 ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลรอบทุนการศึกษาได้

โดยผู้ดูแลระบบสามารถสร้างรอบทุนการศึกษาและกำหนดชื่อทุนการศึกษา ประเภททุน ปีการศึกษา และภาคการศึกษา โดยต้องเลือกประเภททุนจากประเภททุนที่เปิดการใช้งานตามข้อ 1.3.2.14 และระบบดึงเกณฑ์การประเมินเริ่มต้นของประเภททุนนั้นมาใส่ในรอบทุนให้อัตโนมัติ (ถ้าประเภททุนนั้นกำหนดไว้) ผู้ดูแลระบบเปลี่ยนเกณฑ์การประเมินของรอบทุนได้เฉพาะรอบที่เป็น Draft ตามข้อ 1.3.2.4 และหากเปลี่ยนประเภททุนของรอบที่เป็น Draft ระบบแจ้งให้ยืนยันก่อนแทนที่เกณฑ์ที่เลือกไว้ด้วยเกณฑ์เริ่มต้นของประเภทใหม่ แก้ไขข้อมูลหลักของรอบทุนได้เฉพาะรอบทุนที่อยู่ในสถานะ Draft เท่านั้น เมื่อเปิดรอบแล้วจะไม่สามารถแก้ไขข้อมูลหลักของรอบทุนได้ และค้นหาโดยใช้ชื่อทุน ประเภททุน ปีการศึกษา ภาคการศึกษา หรือสถานะรอบทุน ทั้งนี้ ระบบไม่รองรับการลบข้อมูลรอบทุนการศึกษา ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ชื่อทุนการศึกษา  
* ประเภททุน  
* ปีการศึกษา  
* ภาคการศึกษา  
* เกณฑ์การประเมินที่ใช้ในรอบ (1 รอบทุนใช้ 1 เกณฑ์การประเมิน)  
* สถานะรอบทุน (1 \= Draft, 2 \= Open, 3 \= Closed)  
* วันที่และเวลาที่สร้าง

### 1.3.2.4 ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลเกณฑ์การประเมินและเกณฑ์ย่อย รวมถึงเชื่อมโยงเกณฑ์การประเมินกับรอบทุนการศึกษาได้

โดยผู้ดูแลระบบสร้าง "เกณฑ์การประเมิน" ด้วยการกำหนดชื่อเกณฑ์การประเมิน แล้วสร้าง "เกณฑ์ย่อย" ภายใต้เกณฑ์การประเมินนั้น ซึ่งมี 2 ประเภท คือ (1) เกณฑ์ย่อยแบบมีคะแนน ซึ่งกำหนดชื่อหัวข้อ คะแนนสูงสุด และกำหนดว่าอนุญาตหรือไม่อนุญาตให้ผู้ประเมินบันทึกความคิดเห็น (Comment) ในเกณฑ์ย่อยนั้น และ (2) เกณฑ์ย่อยแบบไม่มีคะแนน (ข้อความ) ซึ่งกำหนดเฉพาะชื่อหัวข้อ สำหรับบันทึกข้อมูลประกอบการพิจารณาเพิ่มเติม เช่น ข้อเสนอแนะเรื่องการรับทุนต่อเนื่อง หรือมูลค่าทุนที่สมควรได้รับ หรือหัวข้ออื่นที่ผู้ดูแลระบบต้องการเพิ่มเอง

เมื่อผู้ดูแลระบบกดยืนยันสร้างเกณฑ์การประเมิน ระบบต้องตรวจสอบเงื่อนไขต่อไปนี้ก่อนบันทึกข้อมูลทุกครั้ง หากไม่ผ่านเงื่อนไข ระบบจะแสดงข้อความแจ้งข้อผิดพลาดพร้อมผลรวมคะแนนปัจจุบันและคะแนนรวมเป้าหมาย และไม่อนุญาตให้บันทึกข้อมูล

* ผู้ดูแลระบบต้องกำหนด "คะแนนรวมเป้าหมาย" ของเกณฑ์การประเมินเป็นจำนวนเต็มบวกตั้งแต่ 1 ถึง 1,000  
* ผลรวมคะแนนสูงสุดของเกณฑ์ย่อยแบบมีคะแนนทั้งหมดในเกณฑ์การประเมินต้องเท่ากับคะแนนรวมเป้าหมาย (ไม่นับรวมเกณฑ์ย่อยแบบไม่มีคะแนน)  
* คะแนนสูงสุดของเกณฑ์ย่อยแบบมีคะแนนแต่ละข้อต้องเป็นจำนวนเต็มตั้งแต่ 1 ถึงคะแนนรวมเป้าหมาย

ผู้ดูแลระบบสามารถนำเกณฑ์การประเมินเดียวกันกลับมาใช้ในรอบทุนการศึกษาอื่นได้ทั้งชุด โดย 1 รอบทุนใช้ 1 เกณฑ์การประเมิน และสามารถเลือก เปลี่ยน หรือถอดเกณฑ์การประเมินออกจากรอบทุนได้เฉพาะรอบทุนที่อยู่ในสถานะ Draft เท่านั้น เกณฑ์การประเมินที่ยังไม่ถูกใช้ในรอบทุนที่เป็น Open หรือ Closed สามารถแก้ไขได้ โดยต้องผ่านการตรวจสอบผลรวมเทียบกับคะแนนรวมเป้าหมายทุกครั้งที่ยืนยันบันทึก เมื่อมีรอบทุนที่ใช้เกณฑ์การประเมินนั้นเปลี่ยนเป็น Open แล้ว จะไม่สามารถแก้ไขเกณฑ์การประเมินและเกณฑ์ย่อยได้ หากต้องการเปลี่ยนแปลงรายละเอียดต้องสร้างเกณฑ์การประเมินใหม่แทน และค้นหาโดยใช้ชื่อเกณฑ์การประเมิน ชื่อหัวข้อเกณฑ์ย่อย รอบทุนการศึกษาที่นำเกณฑ์ไปใช้ หรือประเภททุนที่ใช้เกณฑ์เป็นค่าเริ่มต้น ซึ่งข้อมูลประกอบด้วย

* รหัสเกณฑ์การประเมิน  
* ชื่อเกณฑ์การประเมิน  
* คะแนนรวมเป้าหมาย (ผู้ดูแลระบบกำหนด จำนวนเต็ม 1 ถึง 1,000)  
* รหัสเกณฑ์ย่อย  
* ชื่อหัวข้อเกณฑ์ย่อย  
* ประเภทเกณฑ์ย่อย (1 \= มีคะแนน, 2 \= ไม่มีคะแนน/ข้อความ)  
* คะแนนสูงสุด (จำนวนเต็ม 1 ถึงคะแนนรวมเป้าหมาย) (เฉพาะเกณฑ์ย่อยประเภทมีคะแนน)  
* อนุญาตให้บันทึกความคิดเห็น (0 \= ไม่อนุญาต, 1 \= อนุญาต) (เฉพาะเกณฑ์ย่อยประเภทมีคะแนน)  
* ผลรวมคะแนนสูงสุดของเกณฑ์การประเมิน (ระบบคำนวณ แก้ไขโดยตรงไม่ได้)  
* รอบทุนการศึกษาที่นำเกณฑ์ไปใช้  
* ประเภททุนที่ใช้เกณฑ์นี้เป็นเกณฑ์เริ่มต้น

### 1.3.2.5 ผู้ดูแลระบบสามารถนำเข้าข้อมูลผู้สมัครทุนการศึกษาผ่านไฟล์ Excel ได้

โดยผู้ดูแลระบบสามารถนำเข้าข้อมูลผู้สมัครจากไฟล์ Excel (.xlsx) ที่ได้รับจากระบบทุนการศึกษาเดิมเข้าสู่ระบบ SEMS ได้เฉพาะรอบทุนที่อยู่ในสถานะ Draft เท่านั้น โดยระบบแสดงหน้าจอตัวอย่างข้อมูลพร้อมผลการตรวจสอบรายแถว (เลขบัตรประชาชนแสดงแบบปิดบังบางส่วน) และเมื่อผู้ดูแลระบบยืนยัน ระบบจะบันทึกเฉพาะแถวที่ผ่านการตรวจสอบ ส่วนแถวที่ไม่ผ่านจะไม่ถูกนำเข้า ทั้งนี้ ระบบแสดงจำนวนแถวที่ไม่ผ่านและให้ผู้ดูแลระบบกดรับทราบก่อนยืนยัน และไม่อนุญาตให้ยืนยันหากไม่มีแถวใดผ่านการตรวจสอบ การนำเข้าข้อมูลผู้สมัครในรอบทุนที่อยู่ในสถานะ Draft จะถือเป็นการแทนที่ชุดข้อมูลผู้สมัครเดิมของรอบทุนนั้นทั้งหมด โดยข้อมูลผู้สมัครที่นำเข้าแล้วจะไม่สามารถแก้ไขโดยตรงผ่านระบบ SEMS ได้ และไม่อนุญาตให้นำเข้าหรือแทนที่ข้อมูลผู้สมัครในรอบทุนที่เปิดแล้ว (สถานะ Open หรือ Closed) หากต้องการแก้ไขแถวที่ไม่ผ่านหรือพบข้อมูลผิดพลาดในรอบที่ยังเป็น Draft ให้แก้ไขที่ระบบทุนการศึกษาเดิมแล้วนำเข้าไฟล์ใหม่ ซึ่งจะแทนที่ชุดข้อมูลเดิมทั้งหมด ทั้งนี้ ระบบตรวจสอบเฉพาะรูปแบบและเงื่อนไขของข้อมูลตามข้อ 1.3.4.3 ไม่ได้ตรวจสอบความถูกต้องของเนื้อหาเทียบกับระบบทุนการศึกษาเดิม หากพบข้อมูลผิดพลาดหลังเปิดรอบแล้ว ระบบไม่มีกลไกแก้ไขหรือนำเข้าซ้ำ โดยความถูกต้องของข้อมูลต้นทางเป็นความรับผิดชอบของระบบทุนการศึกษาเดิมและมหาวิทยาลัย ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ชื่อไฟล์ที่นำเข้า  
* จำนวนแถวทั้งหมด  
* จำนวนแถวที่ผ่านการตรวจสอบ  
* จำนวนแถวที่ไม่ผ่านการตรวจสอบ  
* รายละเอียดข้อผิดพลาดรายแถว  
* วันที่และเวลาที่นำเข้า

### 1.3.2.6 ผู้ดูแลระบบสามารถ ค้นหา และดูรายชื่อผู้สมัครในรอบทุนการศึกษาได้

โดยค้นหาจากรหัสรอบทุนการศึกษา และกรองรายชื่อโดยใช้รหัสนักศึกษา ชื่อ-นามสกุล หรือคณะ ผู้ดูแลระบบสามารถดูรายชื่อผู้สมัครได้ในทุกสถานะของรอบทุน (Draft, Open และ Closed) เพื่อตรวจทานความครบถ้วนของข้อมูลที่นำเข้า โดยเฉพาะก่อนเปิดรอบ เนื่องจากเมื่อเปิดรอบแล้วไม่สามารถแก้ไขข้อมูลผู้สมัครได้ ระบบแสดงข้อมูลเป็นตารางสำหรับดูเท่านั้น ไม่อนุญาตให้แก้ไข เพิ่ม หรือลบข้อมูลผู้สมัคร และไม่แสดงเลขบัตรประชาชน โทรศัพท์ อีเมล และข้อมูลประกอบการพิจารณา ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* จำนวนผู้สมัครทั้งหมดในรอบทุน  
* รหัสนักศึกษา  
* ชื่อ-นามสกุล (คำนำหน้า, ชื่อ, สกุล)  
* คณะ  
* สาขา  
* ชั้นปี  
* GPA

### 1.3.2.7 ผู้ดูแลระบบสามารถเปิดและปิดรอบทุนการศึกษาได้

โดยผู้ดูแลระบบสามารถเปลี่ยนสถานะรอบทุนจาก Draft เป็น Open เมื่อข้อมูลที่จำเป็นครบถ้วน และเปลี่ยนสถานะจาก Open เป็น Closed ได้ โดยหากมีผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted เลย (เช่น ผู้สมัครที่ไม่เข้าร่วมสัมภาษณ์) ระบบจะแสดงจำนวนและรายชื่อผู้สมัครดังกล่าวให้ผู้ดูแลระบบกดรับทราบก่อนยืนยันปิดรอบ ผู้สมัครเหล่านี้จะมีคะแนนสุดท้ายเป็น 0.00 และไม่สามารถได้รับการจัดสรรทุน สถานะรอบทุนเปลี่ยนได้ทางเดียวเท่านั้น (Draft → Open → Closed) ไม่สามารถย้อนกลับได้ ตั้งแต่รอบทุนอยู่ในสถานะ Open แล้ว จะไม่สามารถแก้ไขข้อมูลหลักของรอบทุน ข้อมูลผู้สมัคร และเกณฑ์การประเมินที่ใช้ในรอบได้ และเมื่อรอบทุนอยู่ในสถานะ Closed แล้ว จะไม่สามารถแก้ไขหรือยืนยันส่งผลการประเมินได้ ผลการประเมินที่ยังเป็น Draft ในรอบที่ปิดแล้วจะถูกล็อก ไม่ถูกนำไปคำนวณคะแนน และยังคงถูกเก็บไว้ในระบบ ในหน้าจอเปลี่ยนสถานะ ระบบแสดงจำนวนแถวที่ไม่ผ่านการตรวจสอบจากการนำเข้าครั้งล่าสุดเพื่อให้ผู้ดูแลระบบรับทราบก่อนเปิดรอบ และแสดงรายชื่อผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted เพื่อใช้ติดตามก่อนปิดรอบ ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ชื่อทุนการศึกษา  
* สถานะรอบทุน (1 \= Draft, 2 \= Open, 3 \= Closed)  
* จำนวนผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted  
* รายชื่อผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted (รหัสนักศึกษา, ชื่อ-นามสกุล)  
* การรับทราบรายชื่อผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted ก่อนปิดรอบ (0 \= ยังไม่รับทราบ, 1 \= รับทราบ; ไม่ต้องรับทราบหากไม่มีผู้สมัครดังกล่าว)  
* จำนวนแถวที่ไม่ผ่านการตรวจสอบจากการนำเข้าครั้งล่าสุด (แสดงตอนเปิดรอบ)  
* วันที่และเวลาที่เปลี่ยนสถานะ

### 1.3.2.8 ผู้ดูแลระบบสามารถ ค้นหา ข้อมูลผลการประเมินและอันดับของผู้สมัครได้

โดยค้นหาจากรหัสรอบทุนการศึกษา และระบบจะแสดงผู้สมัครทุกรายในรอบทุน โดยผู้สมัครที่มีผลการประเมินสถานะ Submitted อย่างน้อย 1 รายการแสดงคะแนนตามที่คำนวณ ส่วนผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted เลยแสดงคะแนนสุดท้ายเป็น 0.00 และจำนวนผลการประเมินเป็น 0 โดยคะแนนสุดท้ายคำนวณจากค่าเฉลี่ยของคะแนนรวมจากผู้ประเมินแต่ละราย (คิดเฉพาะเกณฑ์ย่อยแบบมีคะแนน) แสดงผลทศนิยม 2 ตำแหน่ง ผู้ประเมินทุกคนมีน้ำหนักคะแนนเท่ากัน และเรียงอันดับจากคะแนนมากไปน้อย หากคะแนนเท่ากันให้เรียงตามรหัสนักศึกษาจากน้อยไปมาก (เปรียบเทียบจากคะแนนสุดท้ายก่อนปัดเศษ ทำให้อันดับไม่ซ้ำกัน) และผู้ดูแลระบบสามารถเปิดดูรายละเอียดรายผู้สมัคร เพื่อดูคะแนนและความคิดเห็นรายเกณฑ์ย่อย รวมถึงข้อมูลจากเกณฑ์ย่อยแบบไม่มีคะแนนของผู้ประเมินแต่ละราย พร้อมชื่อผู้ประเมิน (เฉพาะผลการประเมินสถานะ Submitted) เพื่อใช้เปรียบเทียบความแตกต่างของคะแนนระหว่างผู้ประเมิน ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ประเภททุน  
* อันดับ  
* รหัสนักศึกษา  
* ชื่อ-นามสกุลผู้สมัคร  
* คะแนนสุดท้าย (ทศนิยม 2 ตำแหน่ง) พร้อมคะแนนเต็มของรอบทุน (เช่น 132.50 / 150)  
* จำนวนผลการประเมินที่มีสถานะ Submitted  
* ชื่อผู้ประเมิน (ในหน้ารายละเอียดรายผู้สมัคร)  
* คะแนนและความคิดเห็นรายเกณฑ์ย่อยของผู้ประเมินแต่ละราย (ในหน้ารายละเอียดรายผู้สมัคร)  
* ข้อมูลจากเกณฑ์ย่อยแบบไม่มีคะแนนของผู้ประเมินแต่ละราย (ในหน้ารายละเอียดรายผู้สมัคร)

### 1.3.2.9 ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลผลการจัดสรรทุนการศึกษาได้

โดยผู้ดูแลระบบสามารถกำหนดงบประมาณรวมของรอบทุนการศึกษาได้หลังจากรอบทุนนั้นเปลี่ยนเป็นสถานะ Closed แล้วเท่านั้น (เนื่องจากการจัดสรรทุนเป็นฟังก์ชันที่ช่วยให้คณะกรรมการใช้ประกอบการตัดสินใจร่วมกันหลังทราบผลคะแนนครบถ้วน) โดยต้องกำหนดงบประมาณรวมก่อนจึงจะบันทึกผลการจัดสรรรายผู้สมัครได้ และเมื่อกำหนดงบประมาณครั้งแรก ระบบจะสร้างรายการจัดสรรของผู้สมัครทุกรายในรอบทุน โดยมีค่าเริ่มต้นเป็น "ไม่ได้รับทุน" และจำนวนเงิน 0 จากนั้นผู้ดูแลระบบบันทึกว่าผู้สมัครรายใดได้รับทุนและได้รับเงินทุนจำนวนเท่าใด ทั้งนี้ การตัดสินใจว่าผู้สมัครรายใดได้รับทุนและจำนวนเงินเท่าใดเป็นการพิจารณาของคณะกรรมการ โดยระบบทำหน้าที่บันทึกและตรวจสอบข้อมูลการจัดสรร และสามารถแก้ไขงบประมาณรวมได้เฉพาะเมื่อยังไม่มีการบันทึกจัดสรรเงินทุนให้ผู้สมัครรายใด (ยอดเงินที่จัดสรรแล้วเป็น 0\) เนื่องจากโดยปกติกำหนดงบประมาณรวมเพียงครั้งเดียวหลังการประชุมของคณะกรรมการ และสามารถแก้ไขผลการจัดสรรรายผู้สมัครได้เฉพาะในช่วงที่ผลการจัดสรรยังไม่อยู่ในสถานะ Finalized และค้นหาโดยใช้รหัสรอบทุนการศึกษา รหัสนักศึกษา หรือสถานะการได้รับทุน ซึ่งข้อมูลประกอบด้วย

* รหัสการจัดสรรทุน  
* รหัสรอบทุนการศึกษา  
* รหัสนักศึกษา  
* เลขบัตรประชาชน (CITIZENID) — แสดงเฉพาะในหน้ารายละเอียดการจัดสรรรายบุคคล โดยแสดงแบบปิดบังบางส่วน ผู้ดูแลระบบกดเพื่อดูเลขเต็มได้ และระบบบันทึกการดูทุกครั้ง ใช้สำหรับให้เจ้าหน้าที่ประกอบการโอนเงินทุนผ่าน Promptpay นอกระบบ SEMS ไม่แสดงในหน้าตารางรายการจัดสรรที่เห็นพร้อมกันหลายราย  
* โทรศัพท์และอีเมล — แสดงเฉพาะในหน้ารายละเอียดการจัดสรรรายบุคคล สำหรับให้ผู้ดูแลระบบใช้ติดต่อผู้สมัคร  
* จำนวนเงินทุนที่ได้รับอนุมัติ  
* สถานะการได้รับทุน (0 \= ไม่ได้รับทุน \[ค่าเริ่มต้น\], 1 \= ได้รับทุน)  
* งบประมาณรวมของรอบทุน  
* ยอดเงินที่จัดสรรแล้ว (ไม่สามารถแก้ไขได้)  
* ยอดงบประมาณคงเหลือ (ไม่สามารถแก้ไขได้)

ทั้งนี้ ในขั้นตอนการเพิ่มและแก้ไขข้อมูล ระบบต้องตรวจสอบเงื่อนไขต่อไปนี้ก่อนบันทึกข้อมูลทุกครั้ง หากไม่ผ่านเงื่อนไข ระบบจะแจ้งเตือนและไม่อนุญาตให้บันทึกข้อมูล

* ผลรวมของจำนวนเงินทุนที่จัดสรรให้ผู้สมัครทุกรายในรอบทุนต้องไม่เกินงบประมาณรวมของรอบทุนนั้น  
* จำนวนเงินทุนที่ได้รับอนุมัติต้องเป็น 0 เมื่อสถานะการได้รับทุนเป็น "ไม่ได้รับทุน" และต้องมากกว่า 0 เมื่อสถานะเป็น "ได้รับทุน"  
* งบประมาณรวมของรอบทุนต้องมากกว่า 0 บาท  
* การแก้ไขงบประมาณรวมทำได้เฉพาะเมื่อยอดเงินที่จัดสรรแล้วเป็น 0 บาท  
* ผู้สมัครที่คะแนนสุดท้ายเป็น 0 (รวมถึงผู้สมัครที่ไม่มีผลการประเมินสถานะ Submitted) ไม่สามารถกำหนดสถานะเป็น "ได้รับทุน" ได้

หมายเหตุ: ยอดเงินที่จัดสรรแล้วและยอดงบประมาณคงเหลือ เป็นค่าที่ระบบคำนวณโดยอัตโนมัติตามข้อ 1.3.4.6 ผู้ดูแลระบบไม่สามารถแก้ไขค่าทั้งสองนี้โดยตรงได้

### 1.3.2.10 ผู้ดูแลระบบสามารถยืนยันผลการจัดสรรทุนการศึกษาและเปิดผลการจัดสรรที่ยืนยันแล้วกลับมาแก้ไขได้

โดยผู้ดูแลระบบสามารถกดปุ่ม "จัดสรรสำเร็จ" เพื่อยืนยันว่าการจัดสรรเสร็จสิ้นแล้ว และเปลี่ยนสถานะผลการจัดสรรเป็น Finalized หากต้องการแก้ไขผลการจัดสรร เฉพาะผู้ดูแลระบบเท่านั้นที่สามารถเปิดผลการจัดสรรที่อยู่ในสถานะ Finalized กลับมาเป็นสถานะ Editing เพื่อแก้ไข และเมื่อแก้ไขเสร็จสามารถยืนยัน "จัดสรรสำเร็จ" เป็น Finalized อีกครั้งได้ ทั้งนี้ สถานะรอบทุน Closed และสถานะผลการจัดสรร Finalized เป็นคนละสถานะกัน ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* สถานะผลการจัดสรร (1 \= Editing, 2 \= Finalized)  
* ผู้ดำเนินการ (รหัสผู้ดูแลระบบ)  
* วันที่และเวลาที่เปลี่ยนสถานะ

### 1.3.2.11 ผู้ดูแลระบบสามารถ ค้นหา และส่งออกรายงานสรุปผลการประเมินในรูปแบบไฟล์ Excel ได้

โดยค้นหาจากรหัสรอบทุนการศึกษา ซึ่งระบบจะพร้อมให้ส่งออกได้ทันทีที่รอบทุนเปลี่ยนเป็นสถานะ Closed (เมื่อคะแนนของผู้สมัครทุกคนคำนวณและจัดอันดับเสร็จสมบูรณ์แล้ว) และระบบจะสร้างไฟล์รายงานในรูปแบบ Excel (.xlsx) ให้ดาวน์โหลด โดยผู้ดูแลระบบที่ส่งออกต้องกำหนดรหัสผ่านสำหรับเปิดไฟล์ทุกครั้ง ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ชื่อทุนการศึกษา  
* ประเภททุน  
* ข้อมูลผู้สมัคร (รหัสนักศึกษา, ชื่อ-นามสกุล) — **ไม่รวมเลขบัตรประชาชน (CITIZENID)**  
* คะแนนและความคิดเห็นรายเกณฑ์ย่อยของผู้ประเมินแต่ละราย พร้อมชื่อผู้ประเมิน (เพื่อใช้เปรียบเทียบความแตกต่างของคะแนนระหว่างผู้ประเมิน)  
* ข้อมูลจากเกณฑ์ย่อยแบบไม่มีคะแนนของผู้ประเมินแต่ละราย  
* คะแนนรวมของผู้ประเมินแต่ละราย  
* คะแนนสุดท้ายและอันดับ พร้อมคะแนนเต็มของรอบทุน (ผู้สมัครที่ไม่มีผลการประเมินสถานะ Submitted แสดงคะแนนสุดท้าย 0.00)  
* วันที่และเวลาที่ส่งออกรายงาน

### 1.3.2.12 ผู้ดูแลระบบสามารถ ค้นหา และส่งออกรายงานผลการจัดสรรทุนการศึกษาในรูปแบบไฟล์ Excel ได้

โดยค้นหาจากรหัสรอบทุนการศึกษา ซึ่งระบบจะพร้อมให้ส่งออกได้เมื่อสถานะผลการจัดสรรของรอบทุนนั้นเปลี่ยนเป็น Finalized แล้วเท่านั้น (คณะกรรมการยืนยันว่าจัดสรรทุนเสร็จสิ้น) และระบบจะสร้างไฟล์รายงานในรูปแบบ Excel (.xlsx) ให้ดาวน์โหลด โดยผู้ดูแลระบบที่ส่งออกต้องกำหนดรหัสผ่านสำหรับเปิดไฟล์ทุกครั้ง ทั้งนี้ การส่งออกผลการจัดสรรเป็นขั้นตอนสุดท้ายที่ระบบ SEMS รองรับ ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ชื่อทุนการศึกษา  
* ประเภททุน  
* ข้อมูลผู้สมัคร (รหัสนักศึกษา, ชื่อ-นามสกุล)  
* เลขบัตรประชาชน (CITIZENID)  
* คะแนนสุดท้ายและอันดับ พร้อมคะแนนเต็มของรอบทุน  
* ผลการจัดสรรทุนการศึกษา (สถานะการได้รับทุน, จำนวนเงินที่ได้รับอนุมัติ)  
* งบประมาณรวมและยอดเงินที่จัดสรรแล้วของรอบทุน  
* วันที่และเวลาที่ส่งออกรายงาน

### 1.3.2.13 ผู้ดูแลระบบสามารถ ค้นหา และดูประวัติการสมัครทุนการศึกษาของนักศึกษาข้ามรอบทุนได้

โดยค้นหาจากรหัสนักศึกษาหรือชื่อ-นามสกุล ระบบจะแสดงรายการรอบทุนทั้งหมดที่นักศึกษารายนั้นเคยสมัครในระบบ SEMS (เช่น นักศึกษา A สมัครเมื่อชั้นปีที่ 1, 2, 3 และ 4) โดยระบบใช้รหัสนักศึกษาเป็นตัวเชื่อมข้อมูลข้ามรอบทุน และกรองรายการตามประเภททุนหรือปีการศึกษาได้ ระบบแสดงรอบทุนทุกสถานะ (Draft, Open และ Closed) พร้อมสถานะของรอบกำกับ โดยรอบที่ยังไม่เป็น Closed อาจยังไม่มีคะแนนสุดท้ายและอันดับที่สมบูรณ์ เมื่อผู้ดูแลระบบเลือกรอบทุนใดรอบหนึ่ง ระบบแสดงรายละเอียดของรอบนั้น ได้แก่ คะแนนสุดท้ายและอันดับ ผลการได้รับทุนและจำนวนเงิน และคะแนนพร้อมความคิดเห็นรายเกณฑ์ย่อยของผู้ประเมินแต่ละราย (เฉพาะผลการประเมินสถานะ Submitted) ระบบแสดงข้อมูลเป็นการดูเท่านั้น ไม่อนุญาตให้แก้ไข เพิ่ม หรือลบ และไม่แสดงเลขบัตรประชาชน โทรศัพท์ และอีเมลในหน้านี้ ส่วนผู้ประเมินดูประวัติได้เฉพาะข้อมูลแบบจำกัดตามข้อ 1.3.3.3 ทั้งนี้ ระบบบันทึกการเปิดดูประวัติรายนักศึกษาของผู้ดูแลระบบทุกครั้งตามข้อ 1.3.4.10 ซึ่งข้อมูลประกอบด้วย

* รหัสนักศึกษา
* ชื่อ-นามสกุล
* จำนวนรอบทุนที่เคยสมัคร
* รายการรอบทุน: รหัสรอบทุน, ชื่อทุน, ประเภททุน, ปีการศึกษา, ภาคการศึกษา, สถานะรอบทุน, ชั้นปีตอนสมัคร, GPA ตอนสมัคร
* คะแนนสุดท้าย (ทศนิยม 2 ตำแหน่ง) พร้อมคะแนนเต็มของรอบนั้น และอันดับ (เช่น 3 จาก 120 คน)
* ผลการจัดสรร: สถานะการได้รับทุน และจำนวนเงินที่ได้รับอนุมัติ (แสดงเมื่อรอบนั้นมีรายการจัดสรรแล้ว)
* คะแนนและความคิดเห็นรายเกณฑ์ย่อยของผู้ประเมินแต่ละราย พร้อมชื่อผู้ประเมิน (ในหน้ารายละเอียดรายรอบ)

ทั้งนี้ ประวัติครอบคลุมเฉพาะรอบทุนที่ถูกนำเข้าในระบบ SEMS เท่านั้น ไม่รวมการสมัครก่อนเริ่มใช้ SEMS ระบบจับคู่นักศึกษาด้วยรหัสนักศึกษาที่ตรงกันเท่านั้น หากรหัสเปลี่ยนจะไม่เชื่อมประวัติให้ และการนำเข้าไฟล์ใหม่แทนที่ผู้สมัครในรอบ Draft ไม่กระทบประวัติของรอบอื่น

### 1.3.2.14 ผู้ดูแลระบบสามารถ เพิ่ม แก้ไข และค้นหา ข้อมูลประเภททุนการศึกษา รวมถึงกำหนดเกณฑ์การประเมินเริ่มต้นของแต่ละประเภทได้

โดยผู้ดูแลระบบสามารถสร้างประเภททุนการศึกษา (เช่น ทุนเรียนดี ทุนขาดแคลนทุนทรัพย์ ทุนกิจกรรม) กำหนดชื่อประเภททุน คำอธิบายหรือวัตถุประสงค์ของทุน และเลือกเกณฑ์การประเมินเริ่มต้นของประเภทนั้นได้ (ไม่บังคับ) เพื่อให้เกณฑ์การพิจารณาเหมาะกับวัตถุประสงค์ของทุนแต่ละประเภท ไม่ต้องใช้เกณฑ์เดียวกันทั้งหมด ผู้ดูแลระบบสามารถแก้ไขข้อมูลประเภททุน เปิดหรือปิดสถานะการใช้งาน และค้นหาโดยใช้ชื่อประเภททุน สถานะการใช้งาน หรือชื่อเกณฑ์การประเมินเริ่มต้น ทั้งนี้ ระบบไม่รองรับการลบประเภททุน สามารถปิดการใช้งานได้เท่านั้น ประเภททุนที่ปิดการใช้งานไม่สามารถถูกเลือกเมื่อสร้างรอบทุนใหม่ แต่รอบทุนเดิมและประวัติยังแสดงประเภททุนนั้นตามปกติ การเปลี่ยนเกณฑ์การประเมินเริ่มต้นของประเภททุนมีผลกับรอบทุนที่สร้างหลังจากนั้นเท่านั้น ไม่กระทบรอบทุนที่สร้างไว้แล้ว (รวมถึงรอบที่ยังเป็น Draft) และเกณฑ์ที่ถูกใช้เป็นเกณฑ์เริ่มต้นยังอยู่ภายใต้กฎการแก้ไขและล็อกเกณฑ์ตามข้อ 1.3.2.4 ตามเดิม ซึ่งข้อมูลประกอบด้วย

* รหัสประเภททุน
* ชื่อประเภททุน (ไม่ซ้ำกัน)
* คำอธิบาย/วัตถุประสงค์ของทุน
* เกณฑ์การประเมินเริ่มต้น (1 ประเภททุนมีเกณฑ์เริ่มต้นได้ 1 ชุด ไม่บังคับ)
* สถานะการใช้งาน (0 \= ปิดการใช้งาน, 1 \= เปิดการใช้งาน)
* วันที่และเวลาที่สร้าง

### 1.3.2.15 ผู้ดูแลระบบสามารถดูหน้าสรุปข้อมูลวิเคราะห์ของรอบทุนการศึกษาได้

โดยระบบแสดงหน้าสรุปข้อมูลเชิงสถิติ (Analytics Dashboard) จากข้อมูลที่อยู่ในระบบ SEMS เพื่อให้ผู้ดูแลระบบใช้ติดตามความคืบหน้าของรอบทุน ตรวจสอบความสมเหตุสมผลของผลการประเมิน และใช้ประกอบการวางแผนรอบทุนถัดไป หน้านี้แสดงชุดการวิเคราะห์ที่กำหนดตายตัว 6 ส่วนตามรายการด้านล่าง ผู้ดูแลระบบไม่สามารถสร้างกราฟหรือเลือกตัวชี้วัดเองได้ และเป็นการดูเท่านั้น โดยกรองข้อมูลได้ด้วยรอบทุน (เลือกได้หลายรอบ) ปีการศึกษา ภาคการศึกษา ประเภททุน และคณะ ทั้งนี้ การแสดงผลมีเงื่อนไขดังนี้

* ผู้ประเมินไม่สามารถเข้าถึงหน้านี้ได้
* ระบบแสดงเฉพาะข้อมูลสรุปรวม ไม่แสดงชื่อ รหัสนักศึกษา เลขบัตรประชาชน โทรศัพท์ อีเมล หรือความคิดเห็นของผู้ประเมิน และไม่มีการเจาะลึกลงไปถึงรายบุคคลจากหน้านี้ (หากต้องการดูรายบุคคลให้ใช้ข้อ 1.3.2.8 และ 1.3.2.13)
* กลุ่มข้อมูลแยกตามคณะ ชั้นปี หรือช่วง GPA ที่มีผู้สมัครน้อยกว่า 5 ราย ระบบแสดงเป็น "น้อยกว่า 5 ราย" และไม่แสดงค่าเฉลี่ยหรือค่าสถิติของกลุ่มนั้น เพื่อป้องกันการระบุตัวบุคคลจากกลุ่มขนาดเล็ก (**ค่า 5 เป็นข้อเสนอ โปรดยืนยัน**)
* ส่วนที่ 1 และ 2 แสดงได้ทุกสถานะรอบทุน โดยรอบที่ยังไม่ปิดแสดงกำกับว่าเป็นข้อมูลระหว่างดำเนินการ ส่วนที่ 3 ถึง 5 คำนวณเฉพาะรอบทุนที่เป็น Closed และส่วนที่ 6 คำนวณเฉพาะรอบทุนที่ผลการจัดสรรเป็น Finalized
* คะแนนทุกรายการแสดงเป็นร้อยละของคะแนนเต็มของรอบทุนนั้น เพื่อให้เปรียบเทียบข้ามรอบทุนที่มีคะแนนเต็มต่างกันได้ (ไม่ถือเป็นการจัดอันดับรวมข้ามรอบ)
* ตัวชี้วัดเชิงสถิติในส่วนที่ 4 และ 5 แสดงเมื่อข้อมูลถึงเกณฑ์ขั้นต่ำเท่านั้น หากไม่ถึงเกณฑ์ ระบบแสดงว่า "ข้อมูลไม่เพียงพอ" แทนค่า เพื่อไม่ให้ตีความจากข้อมูลน้อยเกินไป (**เกณฑ์ขั้นต่ำเป็นข้อเสนอ: ส่วนที่ 4 ต้องมีผู้สมัครที่มีผลการประเมิน Submitted ตั้งแต่ 20 ราย, ค่าเบี่ยงเบนรายผู้ประเมินต้องมีผู้สมัครที่ประเมินร่วมกับผู้ประเมินอื่นตั้งแต่ 10 ราย, ICC ต้องมีผู้สมัครที่มีผลประเมินตั้งแต่ 2 รายการอย่างน้อย 10 ราย โปรดยืนยัน**)  
* ตัวชี้วัดในส่วนที่ 4 และ 5 เป็นข้อมูลประกอบการพิจารณาของผู้ดูแลระบบเท่านั้น ระบบไม่นำไปปรับคะแนนสุดท้ายหรืออันดับโดยอัตโนมัติ  
* ระบบคำนวณจากข้อมูลปัจจุบันทุกครั้งที่เปิดหน้า ไม่เก็บสำเนาผลสรุป ไม่มีการส่งออกหน้านี้ และไม่บันทึก Audit Log เนื่องจากเป็นข้อมูลสรุปรวม

ชุดการวิเคราะห์ประกอบด้วย

1. **ภาพรวมรอบทุนและความคืบหน้า:** จำนวนผู้สมัคร, จำนวนผู้สมัครที่มีผลการประเมิน Submitted อย่างน้อย 1 รายการ และที่ยังไม่มี, จำนวนผลการประเมินสถานะ Submitted และ Draft, ค่าเฉลี่ยจำนวนผู้ประเมินต่อผู้สมัคร
2. **โปรไฟล์ผู้สมัคร:** จำนวนผู้สมัครแยกตามคณะ ชั้นปี และช่วง GPA (ต่ำกว่า 2.00, 2.00 ถึง 2.49, 2.50 ถึง 2.99, 3.00 ถึง 3.49, 3.50 ถึง 4.00)
3. **การกระจายคะแนนสุดท้าย:** กราฟการกระจายคะแนนสุดท้ายเป็นร้อยละของคะแนนเต็ม (ช่วงละ 10) พร้อมค่าเฉลี่ย มัธยฐาน สูงสุด และต่ำสุด ไม่นับผู้สมัครที่ไม่มีผลการประเมิน Submitted ในกราฟ แต่แสดงจำนวนแยกต่างหาก และแสดงแนวโน้มข้ามรอบ ได้แก่ มัธยฐานและช่วงกลาง 50% (ควอร์ไทล์ที่ 1 ถึง 3) ของคะแนนสุดท้ายรายรอบทุน แยกตามประเภททุน เรียงตามปีการศึกษาและภาคการศึกษา พร้อมติดป้ายเตือนเมื่อการกระจายแคบ (ส่วนเบี่ยงเบนมาตรฐานต่ำกว่า 10 จุดร้อยละของคะแนนเต็ม **ข้อเสนอ โปรดยืนยัน**) ซึ่งอาจบ่งชี้ว่าเกณฑ์ไม่ช่วยแยกผู้สมัคร
4. **คะแนนรายเกณฑ์ย่อย:** ค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานของแต่ละเกณฑ์ย่อยแบบมีคะแนน เป็นร้อยละของคะแนนสูงสุดของเกณฑ์ย่อยนั้น และดัชนีการแยกแยะ (Discrimination Index) ของแต่ละเกณฑ์ย่อย ซึ่งคือผลต่างของค่าเฉลี่ยคะแนนร้อยละของเกณฑ์ย่อยนั้นระหว่างผู้สมัครกลุ่มคะแนนสุดท้ายสูงสุด 30% กับกลุ่มต่ำสุด 30% (ค่ายิ่งสูงยิ่งแยกแยะผู้สมัครได้ดี ค่าติดลบให้ตรวจสอบเกณฑ์ย่อยนั้น) เพื่อดูว่าเกณฑ์ใดแยกแยะผู้สมัครได้ดี หรือผู้สมัครส่วนใหญ่ได้คะแนนใกล้เคียงกัน ใช้ประกอบการปรับเกณฑ์ของรอบทุนถัดไป
5. **ความสอดคล้องของผู้ประเมิน:** รายผู้ประเมิน ได้แก่ จำนวนผลการประเมินสถานะ Submitted และ Draft ค่าเฉลี่ยคะแนนรวมที่ให้เป็นร้อยละของคะแนนเต็ม และ "ค่าเบี่ยงเบนจากผู้ประเมินคนอื่น" ซึ่งคือค่าเฉลี่ยของผลต่างระหว่างคะแนนรวมที่ผู้ประเมินให้ กับค่าเฉลี่ยคะแนนรวมที่ผู้ประเมินคนอื่นให้ผู้สมัครคนเดียวกัน (หน่วยเป็นจุดร้อยละของคะแนนเต็ม ค่าบวกคือให้คะแนนสูงกว่าผู้อื่น ค่าลบคือต่ำกว่า) การเทียบเฉพาะผู้สมัครคนเดียวกันเหมาะกับระบบนี้ที่ผู้ประเมินแต่ละคนประเมินผู้สมัครคนละชุด ในภาพรวม ได้แก่ ส่วนต่างคะแนนเฉลี่ยระหว่างผู้ประเมินที่ประเมินผู้สมัครคนเดียวกัน (เฉพาะผู้สมัครที่มีผล Submitted ตั้งแต่ 2 รายการ) และค่าสหสัมพันธ์ภายในชั้น (ICC) พร้อมระดับการแปลผล ใช้ตรวจสอบความสอดคล้องของการให้คะแนน ไม่ใช่การประเมินผลงานของผู้ประเมิน
6. **ผลการจัดสรรและแนวโน้ม:** งบประมาณรวม ยอดจัดสรร ยอดคงเหลือ จำนวนผู้ได้รับทุน อัตราการได้รับทุน (จำนวนผู้ได้รับทุนต่อจำนวนผู้สมัคร) และจำนวนเงินเฉลี่ยต่อผู้ได้รับทุน แยกตามคณะ ชั้นปี และประเภททุน และแนวโน้มข้ามรอบตามปีการศึกษาและภาคการศึกษา รวมถึงเปรียบเทียบสัดส่วนผู้สมัครกับสัดส่วนผู้ได้รับทุนของแต่ละกลุ่ม และคะแนนต่ำสุดของผู้ได้รับทุนในแต่ละรอบ (ร้อยละของคะแนนเต็ม แสดงเมื่อมีผู้ได้รับทุนตั้งแต่ 5 ราย) เพื่อใช้เป็นข้อมูลอ้างอิงในการกำหนดแนวทางการจัดสรรรอบถัดไป

ซึ่งข้อมูลประกอบด้วย

* ตัวกรอง: รหัสรอบทุนการศึกษา, ปีการศึกษา, ภาคการศึกษา, ประเภททุน, คณะ
* ส่วนที่ 1: จำนวนผู้สมัคร, จำนวนผู้สมัครที่มี/ไม่มีผลการประเมิน Submitted, จำนวนผลการประเมิน Submitted และ Draft, จำนวนผู้ประเมินเฉลี่ยต่อผู้สมัคร
* ส่วนที่ 2: จำนวนผู้สมัครแยกตามคณะ ชั้นปี และช่วง GPA
* ส่วนที่ 3: การกระจายคะแนนสุดท้าย (ร้อยละของคะแนนเต็ม), ค่าเฉลี่ย, มัธยฐาน, ควอร์ไทล์ที่ 1 และ 3, สูงสุด, ต่ำสุด, ส่วนเบี่ยงเบนมาตรฐาน, จำนวนผู้สมัครที่ไม่มีผลการประเมิน Submitted, แนวโน้มข้ามรอบแยกตามประเภททุน
* ส่วนที่ 4: ชื่อหัวข้อเกณฑ์ย่อย, ค่าเฉลี่ย (ร้อยละของคะแนนสูงสุด), ส่วนเบี่ยงเบนมาตรฐาน, ดัชนีการแยกแยะ
* ส่วนที่ 5: ชื่อผู้ประเมิน, จำนวนผลการประเมิน Submitted และ Draft, ค่าเฉลี่ยคะแนนรวมที่ให้ (ร้อยละของคะแนนเต็ม), ค่าเบี่ยงเบนจากผู้ประเมินคนอื่น, ส่วนต่างคะแนนเฉลี่ยระหว่างผู้ประเมิน, ค่า ICC และระดับการแปลผล
* ส่วนที่ 6: งบประมาณรวม, ยอดเงินที่จัดสรรแล้ว, ยอดงบประมาณคงเหลือ, จำนวนผู้ได้รับทุน, อัตราการได้รับทุน, จำนวนเงินเฉลี่ยต่อผู้ได้รับทุน, แนวโน้มตามปีการศึกษาและภาคการศึกษา, สัดส่วนผู้สมัครเทียบผู้ได้รับทุนรายกลุ่ม, คะแนนต่ำสุดของผู้ได้รับทุน

* บทบาทผู้ใช้งาน  
* สถานะการใช้งานบัญชี

### 1.3.3.2 ผู้ประเมินสามารถ ค้นหา และเลือกผู้สมัครทุนการศึกษาที่เปิดให้ประเมินได้

โดยระบบจะแสดงเฉพาะผู้สมัครในรอบทุนที่อยู่ในสถานะ Open ผู้ประเมินสามารถเลือกประเมินผู้สมัครได้หลายราย และประเมินผู้สมัครรายเดียวกันได้พร้อมกันโดยไม่จำกัดจำนวนผู้ประเมิน แต่ไม่สามารถประเมินผู้สมัครรายเดิมซ้ำในรอบทุนเดียวกันได้ และค้นหาโดยใช้รหัสนักศึกษาหรือชื่อ-นามสกุล ทั้งนี้ บัญชีผู้ประเมินที่พ้นวันหมดอายุแต่ยังเปิดใช้งานอยู่ตามข้อ 1.3.2.2 เลือกได้เฉพาะผู้สมัครที่ตนเองมีผลการประเมินสถานะ Draft อยู่แล้ว และไม่สามารถเริ่มประเมินผู้สมัครรายใหม่ได้ ซึ่งข้อมูลประกอบด้วย

* รหัสผู้สมัคร  
* รหัสนักศึกษา  
* ชื่อ-นามสกุล  
* จำนวนผู้ประเมินที่ประเมินผู้สมัครรายนี้แล้ว (Submitted)  
* สถานะการประเมินของตนเอง (1 \= Draft, 2 \= Submitted)

### 1.3.3.3 ผู้ประเมินสามารถดูรายละเอียดข้อมูลผู้สมัคร ข้อมูลประกอบการพิจารณา และประวัติการสมัครและการได้รับทุนของผู้สมัครในระบบ SEMS ได้

โดยระบบแสดงข้อมูลผู้สมัครและข้อมูลประกอบการพิจารณาที่นำเข้ามาจากระบบเดิม เพื่อให้ผู้ประเมินใช้ประกอบการประเมินจากหน้าการประเมินเดียวกัน โดยไม่อนุญาตให้แก้ไข เพิ่ม หรือลบข้อมูลผู้สมัคร ทั้งนี้ ระบบไม่แสดงเลขบัตรประชาชน โทรศัพท์ และอีเมลของผู้สมัครแก่ผู้ประเมิน นอกจากนี้ ระบบแสดงประวัติการสมัครของผู้สมัครรายนั้นในรอบทุนก่อนหน้าที่อยู่ในระบบ SEMS โดยเชื่อมด้วยรหัสนักศึกษา เพื่อใช้ประกอบการประเมิน ระบบแสดงเฉพาะรอบทุนที่อยู่ในสถานะ Closed และไม่รวมรอบทุนที่กำลังประเมินอยู่ ระบบแสดงผลการได้รับทุนและจำนวนเงินของรอบนั้นเมื่อสถานะผลการจัดสรรของรอบนั้นเป็น Finalized เท่านั้น หากยังไม่ Finalized แสดงเป็น "ยังไม่สรุปผล" ทั้งนี้ ระบบไม่แสดงคะแนนสุดท้าย อันดับ คะแนนหรือความคิดเห็นรายเกณฑ์ย่อย หรือชื่อของผู้ประเมินรายอื่นในรอบก่อนหน้าแก่ผู้ประเมิน และแสดงประวัติจากระบบ SEMS แยกจากข้อมูล "ทุนที่เคยได้รับ" ที่นำเข้าจากระบบทุนการศึกษาเดิม ซึ่งข้อมูลประกอบด้วย

* รหัสนักศึกษา  
* คำนำหน้า, ชื่อ, สกุล  
* คณะ, สาขา, ชั้นปี  
* GPA  
* ข้อมูลประกอบการพิจารณา ได้แก่ วันที่สมัคร ที่พัก ค่าเช่าหอ/บ้าน ค่าใช้จ่ายส่วนตัว ค่าอุปกรณ์การศึกษา อุปกรณ์อิเล็กทรอนิกส์ที่มี รายได้เสริม ข้อมูลบิดา-มารดา (อายุ อาชีพ รายได้ สภาพ) สภาพบิดา-มารดา คนออกเงินเรียน ข้อมูลผู้อุปการะ ข้อมูลพี่น้อง ข้อมูล กยศ. และทุนที่เคยได้รับ (ตามที่ระบบเดิมแจ้ง SEMS ไม่ได้ตรวจสอบ)  
* ประวัติการสมัครในระบบ SEMS (เฉพาะรอบทุน Closed ก่อนหน้า): ชื่อทุน, ประเภททุน, ปีการศึกษา, ภาคการศึกษา, ชั้นปีตอนสมัคร, ผลการได้รับทุน (ได้รับทุน / ไม่ได้รับทุน / ยังไม่สรุปผล), จำนวนเงินที่ได้รับอนุมัติ

### 1.3.3.4 ผู้ประเมินสามารถ กรอก แก้ไข คะแนนและความคิดเห็นในแต่ละเกณฑ์ย่อยในสถานะ Draft ได้

โดยหน้าการประเมินแบ่งพื้นที่แสดงข้อมูลผู้สมัครและส่วนสำหรับกรอกผลการประเมิน ผู้ประเมินสามารถกำหนดคะแนนในแต่ละเกณฑ์ย่อยแบบมีคะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึงคะแนนสูงสุดของเกณฑ์ย่อย และบันทึกความคิดเห็นได้เฉพาะเกณฑ์ย่อยที่ผู้ดูแลระบบอนุญาตให้บันทึกความคิดเห็น สำหรับเกณฑ์ย่อยแบบไม่มีคะแนน ผู้ประเมินสามารถกรอกข้อความได้ตามต้องการ โดยเป็นการกรอกที่ไม่บังคับ โดยระบบบันทึกผลการประเมินในสถานะ Draft และบันทึกข้อมูลโดยอัตโนมัติระหว่างการประเมิน ซึ่งข้อมูลประกอบด้วย

* รหัสการประเมิน  
* รหัสเกณฑ์ย่อย  
* ชื่อหัวข้อเกณฑ์ย่อย  
* ประเภทเกณฑ์ย่อย (1 \= มีคะแนน, 2 \= ไม่มีคะแนน/ข้อความ)  
* คะแนนสูงสุดของเกณฑ์ย่อย (เฉพาะเกณฑ์ย่อยประเภทมีคะแนน)  
* อนุญาตให้บันทึกความคิดเห็น (เฉพาะเกณฑ์ย่อยประเภทมีคะแนน)  
* คะแนนที่ให้ (เฉพาะเกณฑ์ย่อยประเภทมีคะแนน) หรือข้อความที่กรอก (เฉพาะเกณฑ์ย่อยประเภทไม่มีคะแนน)  
* ความคิดเห็นรายเกณฑ์ย่อย (เฉพาะเกณฑ์ย่อยที่อนุญาต)  
* สถานะการประเมิน (1 \= Draft, 2 \= Submitted)  
* วันที่และเวลาที่บันทึกครั้งล่าสุด

### 1.3.3.5 ผู้ประเมินสามารถตรวจสอบสรุปผลการประเมินก่อนยืนยันส่งผลได้

โดยระบบแสดงหน้า Preview สรุปคะแนนและความคิดเห็นทุกเกณฑ์ย่อย รวมถึงข้อมูลจากเกณฑ์ย่อยแบบไม่มีคะแนน เพื่อให้ตรวจทานก่อนยืนยันส่งผล และสามารถย้อนกลับไปแก้ไขได้ตราบที่ยังไม่ยืนยันส่งผล ซึ่งข้อมูลประกอบด้วย

* รหัสการประเมิน  
* ชื่อหัวข้อเกณฑ์ย่อย  
* คะแนนที่ให้หรือข้อความที่กรอกในแต่ละเกณฑ์ย่อย  
* ความคิดเห็นรายเกณฑ์ย่อย (เฉพาะเกณฑ์ย่อยที่อนุญาต)  
* คะแนนรวมเบื้องต้น (คำนวณชั่วคราวเพื่อการตรวจทานเท่านั้น เฉพาะเกณฑ์ย่อยแบบมีคะแนน) แสดงเทียบกับคะแนนรวมเป้าหมาย (เช่น 87 / 150)

### 1.3.3.6 ผู้ประเมินสามารถยืนยันส่งผลการประเมินได้

โดยผู้ประเมินต้องกรอกคะแนนของเกณฑ์ย่อยแบบมีคะแนนครบทุกเกณฑ์ (ส่วนความคิดเห็นและเกณฑ์ย่อยแบบไม่มีคะแนนไม่บังคับ) จึงจะยืนยันส่งผลได้ เมื่อผู้ประเมินยืนยันส่งผล ระบบจะเปลี่ยนสถานะผลการประเมินจาก Draft เป็น Submitted และไม่อนุญาตให้แก้ไขผลการประเมินดังกล่าวอีก ซึ่งข้อมูลประกอบด้วย

* รหัสการประเมิน  
* สถานะการประเมิน (1 \= Draft, 2 \= Submitted)  
* คะแนนรวมของผู้ประเมิน  
* วันที่และเวลาที่ยืนยันส่งผล

## 1.3.4 ส่วนการทำงานของระบบ มีฟังก์ชันดังนี้

### 1.3.4.1 ระบบสามารถยืนยันตัวตนผู้ใช้งานและตรวจสอบสิทธิ์การเข้าถึงตามบทบาทได้

โดยระบบใช้ KKU Single Sign-On (KKU SSO) สำหรับการยืนยันตัวตน และระบบ SEMS ตรวจสอบบทบาทและสิทธิ์การเข้าถึงฟังก์ชันของผู้ใช้งาน รวมถึงเปลี่ยนสถานะบัญชีผู้ประเมินเป็นปิดการใช้งานโดยอัตโนมัติเมื่อถึงวันหมดอายุตามเงื่อนไขในข้อ 1.3.2.2 ซึ่งข้อมูลประกอบด้วย

* บัญชีผู้ใช้งาน  
* บทบาทผู้ใช้งาน  
* สถานะการใช้งานบัญชี  
* วันหมดอายุของบัญชี (เฉพาะบทบาท Evaluator)

### 1.3.4.2 ระบบสามารถตรวจสอบความพร้อมของรอบทุนก่อนอนุญาตให้เปิดรอบได้

โดยค้นหาจากรหัสรอบทุนการศึกษา และตรวจสอบเงื่อนไขตามกฎที่กำหนด หากไม่ผ่านเงื่อนไขระบบจะแจ้งเตือนและไม่อนุญาตให้เปลี่ยนสถานะจาก Draft เป็น Open ซึ่งข้อมูลที่ใช้ตรวจสอบประกอบด้วย

* ข้อมูลหลักของรอบทุน รวมถึงประเภททุน (ต้องครบถ้วน)  
* จำนวนผู้สมัครในรอบทุน (ต้องมีอย่างน้อย 1 คน)  
* จำนวนแถวที่ไม่ผ่านการตรวจสอบจากการนำเข้าครั้งล่าสุด (แสดงเพื่อให้ผู้ดูแลระบบรับทราบก่อนเปิดรอบ ไม่ใช่เงื่อนไขห้ามเปิดรอบ)  
* เกณฑ์การประเมินที่เชื่อมโยงกับรอบทุน (ต้องมี 1 เกณฑ์การประเมิน และตรวจซ้ำว่าผลรวมคะแนนสูงสุดของเกณฑ์ย่อยแบบมีคะแนนเท่ากับคะแนนรวมเป้าหมายของเกณฑ์การประเมิน)  
* ผลการตรวจสอบความพร้อม (0 \= ไม่ผ่าน, 1 \= ผ่าน)

### 1.3.4.3 ระบบสามารถอ่านและตรวจสอบข้อมูลจากไฟล์ Excel ก่อนนำเข้าข้อมูลผู้สมัครได้

โดยระบบอ่านข้อมูลจากไฟล์ Excel ที่ผู้ดูแลระบบนำเข้า ตรวจสอบข้อมูลในคอลัมน์ที่กำหนดและรูปแบบข้อมูล และแสดงผลการตรวจสอบพร้อมระบุแถวและสาเหตุของข้อผิดพลาดก่อนบันทึกลงฐานข้อมูล โดยกฎการตรวจสอบประกอบด้วย ไฟล์ต้องเป็น .xlsx และมีขนาดไม่เกินที่ระบบกำหนด มีคอลัมน์บังคับครบ รหัสนักศึกษาไม่ซ้ำกันภายในไฟล์ GPA อยู่ในช่วง 0.00 ถึง 4.00 และเลขบัตรประชาชนเป็นตัวเลข 13 หลัก แถวที่ไม่ผ่านจะไม่ถูกนำเข้า ส่วนแถวที่ผ่านจะถูกบันทึกเมื่อผู้ดูแลระบบยืนยัน ทั้งนี้ ระบบตรวจสอบเฉพาะรูปแบบและเงื่อนไขของข้อมูลตามกฎข้างต้น ไม่ตรวจสอบความถูกต้องของเนื้อหาเทียบกับระบบทุนการศึกษาเดิม และในการแสดงผลและการบันทึกข้อผิดพลาด ระบบไม่แสดงหรือบันทึกเลขบัตรประชาชนแบบเต็ม และระบบลบไฟล์ชั่วคราวที่อัปโหลดทิ้งเมื่อการนำเข้าเสร็จสิ้นหรือถูกยกเลิก ซึ่งข้อมูลประกอบด้วย

* ข้อมูลคอลัมน์บังคับ: รหัสนักศึกษา, คำนำหน้า, ชื่อ, สกุล, คณะ, สาขา, ชั้นปี, GPA, โทรศัพท์, อีเมล (เก็บไว้เพื่อให้ผู้ดูแลระบบติดต่อผู้สมัคร), เลขบัตรประชาชน (CITIZENID)  
* ข้อมูลคอลัมน์ประกอบการพิจารณา: วันที่สมัคร, ที่พัก, ค่าเช่าหอ/บ้าน, ค่าใช้จ่ายส่วนตัว, ค่าอุปกรณ์การศึกษา, อุปกรณ์อิเล็กทรอนิกส์ที่มี, รายได้เสริม, ข้อมูลบิดา-มารดา (อายุ อาชีพ รายได้ สภาพ), สภาพบิดา-มารดา, คนออกเงินเรียน, ข้อมูลผู้อุปการะ, ข้อมูลพี่น้อง, ข้อมูล กยศ., ทุนที่เคยได้รับ  
* ผลการตรวจสอบรายแถว  
* สาเหตุของข้อผิดพลาดรายแถว  
* จำนวนแถวที่ผ่านและไม่ผ่านการตรวจสอบ

### 1.3.4.4 ระบบสามารถ คำนวณ และจัดอันดับคะแนนของผู้สมัครจากผลการประเมินที่มีสถานะ Submitted ได้

โดยค้นหาจากรหัสรอบทุนการศึกษา และนับเฉพาะผลการประเมินที่มีสถานะ Submitted (ผลการประเมินสถานะ Draft ไม่ถูกนำมาคำนวณ) คำนวณคะแนนรวมของผู้ประเมินแต่ละราย (เฉพาะเกณฑ์ย่อยแบบมีคะแนน) และคำนวณคะแนนสุดท้ายจากค่าเฉลี่ยของคะแนนรวมจากผู้ประเมินแต่ละรายเมื่อมีผลการประเมิน Submitted อย่างน้อย 1 รายการ โดยผู้ประเมินทุกคนมีน้ำหนักเท่ากัน แสดงผลคะแนนสุดท้ายเป็นทศนิยม 2 ตำแหน่ง ผู้สมัครที่ยังไม่มีผลการประเมินสถานะ Submitted เลยจะมีคะแนนสุดท้ายเป็น 0.00 จากนั้นจัดอันดับผู้สมัครทุกรายตามคะแนนสุดท้ายจากมากไปน้อย หากคะแนนเท่ากันให้เรียงตามรหัสนักศึกษาจากน้อยไปมาก (เปรียบเทียบจากคะแนนสุดท้ายก่อนปัดเศษ ทำให้อันดับไม่ซ้ำกัน) ทั้งนี้ ระบบจัดอันดับเฉพาะภายในรอบทุนเดียวกัน ไม่เปรียบเทียบหรือจัดอันดับคะแนนข้ามรอบทุนที่มีคะแนนเต็มต่างกัน ซึ่งข้อมูลผลลัพธ์ประกอบด้วย

* รหัสผู้สมัคร  
* จำนวนผลการประเมินที่มีสถานะ Submitted  
* คะแนนรวมของผู้ประเมินแต่ละราย  
* คะแนนสุดท้าย (ทศนิยม 2 ตำแหน่ง) พร้อมคะแนนเต็มของรอบทุน (เช่น 132.50 / 150)  
* อันดับ

### 1.3.4.5 ระบบสามารถตรวจสอบและแสดงผู้สมัครที่ยังไม่มีผลการประเมินก่อนปิดรอบทุนการศึกษาได้

โดยค้นหาจากรหัสรอบทุนการศึกษา และตรวจสอบผู้สมัครทุกคนในรอบทุนว่ามีผลการประเมินสถานะ Submitted อย่างน้อย 1 รายการหรือไม่ หากมีผู้สมัครอย่างน้อยหนึ่งรายที่ยังไม่มีผลการประเมิน Submitted เลย ระบบจะแสดงจำนวนและรายชื่อผู้สมัครดังกล่าวให้ผู้ดูแลระบบกดรับทราบ และอนุญาตให้ปิดรอบทุนได้หลังจากรับทราบแล้วเท่านั้น หากไม่มีผู้สมัครดังกล่าวสามารถปิดรอบได้ทันที เมื่อปิดรอบทุนแล้ว ระบบจะล็อกผลการประเมินที่ยังเป็น Draft โดยไม่นำไปคำนวณคะแนนและยังคงเก็บไว้ในระบบ และผู้สมัครที่ไม่มีผลการประเมิน Submitted จะมีคะแนนสุดท้ายเป็น 0.00 และไม่สามารถได้รับการจัดสรรทุน ซึ่งข้อมูลที่ใช้ตรวจสอบประกอบด้วย

* รหัสรอบทุนการศึกษา  
* จำนวนผู้สมัครทั้งหมด  
* จำนวนผู้สมัครที่มีผลการประเมินสถานะ Submitted อย่างน้อย 1 รายการ  
* จำนวนผู้สมัครที่ยังไม่มีผลการประเมิน Submitted  
* รายชื่อผู้สมัครที่ยังไม่มีผลการประเมิน Submitted (รหัสนักศึกษา, ชื่อ-นามสกุล)  
* ผลการรับทราบของผู้ดูแลระบบ (0 \= ยังไม่รับทราบ, 1 \= รับทราบ หรือไม่มีผู้สมัครที่ต้องรับทราบ)

### 1.3.4.6 ระบบสามารถตรวจสอบงบประมาณและผลการจัดสรรทุนการศึกษาได้

โดยค้นหาจากรหัสรอบทุนการศึกษา และคำนวณจากงบประมาณรวม (ซึ่งกำหนดได้หลังรอบทุนเปลี่ยนเป็น Closed แล้ว) หักด้วยยอดเงินที่จัดสรรให้ผู้สมัครทุกรายในรอบทุนนั้น โดยคำนวณใหม่ทันทีที่มีการเปลี่ยนแปลงการจัดสรร และไม่อนุญาตให้ยอดเงินจัดสรรรวมเกินงบประมาณรวมของรอบทุน ไม่อนุญาตให้กำหนดงบประมาณรวมน้อยกว่าหรือเท่ากับ 0 บาท และไม่อนุญาตให้แก้ไขงบประมาณรวมเมื่อมียอดเงินที่จัดสรรแล้วมากกว่า 0 ซึ่งข้อมูลผลลัพธ์ประกอบด้วย

* รหัสรอบทุนการศึกษา  
* งบประมาณรวม  
* ยอดเงินที่จัดสรรแล้ว  
* ยอดงบประมาณคงเหลือ  
* จำนวนผู้สมัครที่ได้รับการจัดสรรทุน

### 1.3.4.7 ระบบสามารถจัดการสถานะผลการจัดสรรทุนการศึกษาได้

โดยผลการจัดสรรมีสถานะ Editing และ Finalized ระบบสร้างสถานะผลการจัดสรรเป็น Editing โดยอัตโนมัติเมื่อมีการกำหนดงบประมาณรวมของรอบทุนครั้งแรก เมื่อผู้ดูแลระบบยืนยันว่าการจัดสรรเสร็จสิ้นแล้ว ระบบจะเปลี่ยนสถานะเป็น Finalized และไม่อนุญาตให้แก้ไขผลการจัดสรร จนกว่าผู้ดูแลระบบจะเปิดแก้ไข ซึ่งระบบจะเปลี่ยนสถานะกลับเป็น Editing ทั้งนี้ สถานะผลการจัดสรรแยกจากสถานะรอบทุนอย่างชัดเจน ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* สถานะผลการจัดสรร (1 \= Editing, 2 \= Finalized)  
* วันที่และเวลาที่เปลี่ยนสถานะ

### 1.3.4.8 ระบบสามารถค้นหาและส่งออกรายงานสรุปผลการประเมินในรูปแบบไฟล์ Excel ได้

โดยค้นหาจากรหัสรอบทุนการศึกษาซึ่งอยู่ในสถานะ Closed ตรวจสอบสิทธิ์ของผู้ใช้งานที่ขอดาวน์โหลด รวบรวมข้อมูลผู้สมัคร ผลการประเมินรายผู้ประเมิน คะแนนสุดท้าย และอันดับ และสร้างเป็นไฟล์ Excel (.xlsx) ที่ป้องกันด้วยรหัสผ่านซึ่งผู้ดูแลระบบที่ส่งออกกำหนด และบันทึกการส่งออกในบันทึกการใช้งาน (Log) โดยชุดข้อมูลที่ส่งออกเป็นชุดที่กำหนดไว้ตายตัว ผู้ใช้ไม่สามารถเลือกคอลัมน์เองได้ ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ข้อมูลที่ส่งออก (ประเภททุน, คะแนนเต็มของรอบทุน, ข้อมูลผู้สมัคร — ไม่รวมเลขบัตรประชาชน, คะแนนและความคิดเห็นรายผู้ประเมินพร้อมชื่อผู้ประเมิน, ข้อมูลจากเกณฑ์ย่อยแบบไม่มีคะแนน, คะแนนสุดท้าย, อันดับ; ผู้สมัครที่ไม่มีผลการประเมินสถานะ Submitted แสดงคะแนนสุดท้าย 0.00)  
* วันที่และเวลาที่ส่งออกรายงาน

### 1.3.4.9 ระบบสามารถค้นหาและส่งออกรายงานผลการจัดสรรทุนการศึกษาในรูปแบบไฟล์ Excel ได้

โดยค้นหาจากรหัสรอบทุนการศึกษาซึ่งสถานะผลการจัดสรรเป็น Finalized แล้วเท่านั้น ตรวจสอบสิทธิ์ของผู้ใช้งานที่ขอดาวน์โหลด รวบรวมข้อมูลผู้สมัคร คะแนนสุดท้าย อันดับ และผลการจัดสรรทุน และสร้างเป็นไฟล์ Excel (.xlsx) ที่ป้องกันด้วยรหัสผ่านซึ่งผู้ดูแลระบบที่ส่งออกกำหนด และบันทึกการส่งออกในบันทึกการใช้งาน (Log) ซึ่งข้อมูลประกอบด้วย

* รหัสรอบทุนการศึกษา  
* ข้อมูลที่ส่งออก (ประเภททุน, คะแนนเต็มของรอบทุน, ข้อมูลผู้สมัครรวมเลขบัตรประชาชนสำหรับใช้โอนเงินทุน, คะแนนสุดท้ายและอันดับ, ผลการจัดสรรทุน, งบประมาณ)  
* วันที่และเวลาที่ส่งออกรายงาน

### 1.3.4.10 ระบบสามารถคุ้มครองข้อมูลส่วนบุคคลได้

ระบบ SEMS อยู่ในความดูแลของคณะวิศวกรรมศาสตร์ มหาวิทยาลัยขอนแก่น และดำเนินการตามนโยบายคุ้มครองข้อมูลส่วนบุคคลและนโยบายความมั่นคงปลอดภัยด้านเทคโนโลยีสารสนเทศของมหาวิทยาลัย โดยระบบจัดเก็บข้อมูลส่วนบุคคลของผู้สมัครเท่าที่จำเป็นต่อการพิจารณาทุน รวมถึงเลขบัตรประชาชนซึ่งจำเป็นต้องเก็บเพื่อใช้ประกอบการโอนเงินทุน และดำเนินการให้สอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ระบบมีมาตรการดังนี้

* **บันทึกการใช้งาน (Audit Log):** ระบบบันทึกผู้ดำเนินการ วันและเวลา และรายการที่ดำเนินการ สำหรับการดูเลขบัตรประชาชนแบบเต็ม การส่งออกรายงาน การนำเข้าข้อมูลผู้สมัคร การเปลี่ยนสถานะรอบทุน (กรณีปิดรอบให้บันทึกจำนวนผู้สมัครที่ยังไม่มีผลการประเมินซึ่งผู้ดูแลระบบรับทราบ) และสถานะผลการจัดสรร การเพิ่ม แก้ไข เปิด-ปิดบัญชีผู้ใช้งาน การเพิ่มและแก้ไขเกณฑ์การประเมินและเกณฑ์ย่อย การยืนยันส่งผลการประเมิน การกำหนดและแก้ไขงบประมาณรวม การแก้ไขผลการจัดสรรรายบุคคล การเพิ่มและแก้ไขประเภททุน (รวมการเปิด-ปิดสถานะและการเปลี่ยนเกณฑ์เริ่มต้น) และการเปิดดูประวัติการสมัครรายนักศึกษาของผู้ดูแลระบบ โดยกรณีแก้ไขข้อมูลระบบบันทึกทั้งค่าเดิมและค่าใหม่ในทุกการแก้ไข (รวมถึงการแก้ไขซ้ำหลังเปิดผลการจัดสรรที่ Finalized กลับมาแก้ไข) โดย SEMS ไม่มีหน้าจอค้นดู Log การตรวจสอบ Log ดำเนินการโดยผู้ดูแลระบบเซิร์ฟเวอร์นอก SEMS และเก็บ Log ตามนโยบายความมั่นคงปลอดภัยด้านสารสนเทศของมหาวิทยาลัย  
* **การปกป้องเลขบัตรประชาชน:** ระบบเก็บเลขบัตรประชาชนแบบเข้ารหัสในฐานข้อมูล แสดงผลแบบปิดบังบางส่วน และการดูเลขเต็มทำได้เฉพาะผู้ดูแลระบบผ่านการกดดูซึ่งถูกบันทึกทุกครั้ง การรับส่งข้อมูลระหว่างผู้ใช้กับระบบใช้การเข้ารหัสผ่าน HTTPS  
* **การจำกัดสิทธิ์:** ผู้ประเมินไม่สามารถเข้าถึงเลขบัตรประชาชน โทรศัพท์ และอีเมลของผู้สมัคร ส่วนข้อมูลดังกล่าวผู้ดูแลระบบเข้าถึงได้เฉพาะหน้ารายละเอียดการจัดสรรรายบุคคลและรายงานผลการจัดสรร ผู้ประเมินเข้าถึงประวัติการสมัครของผู้สมัครได้เฉพาะข้อมูลแบบจำกัดตามข้อ 1.3.3.3 ส่วนประวัติฉบับเต็มรวมคะแนนและความคิดเห็นรายผู้ประเมินเข้าถึงได้เฉพาะผู้ดูแลระบบ  
* **การป้องกันไฟล์ส่งออก:** ไฟล์ Excel ที่ส่งออกต้องตั้งรหัสผ่านโดยผู้ดูแลระบบที่ส่งออก และการส่งออกทุกครั้งถูกบันทึกใน Log  
* **ไฟล์ชั่วคราว:** ไฟล์ Excel ที่อัปโหลดเพื่อนำเข้าถูกลบทิ้งเมื่อนำเข้าเสร็จสิ้นหรือถูกยกเลิก  
* **ระยะเวลาเก็บรักษา:** ข้อมูลที่ผูกกับผู้สมัคร ได้แก่ ข้อมูลผู้สมัคร ผลการประเมิน ความคิดเห็น ข้อมูลจากเกณฑ์ย่อยแบบไม่มีคะแนน และผลการจัดสรรทุน ถูกเก็บเป็นเวลา 6 ปี นับจากวันที่นำเข้าข้อมูลเข้าสู่ระบบ เมื่อครบกำหนด ผู้ดูแลฐานข้อมูลดำเนินการทำให้ข้อมูลผู้สมัครไม่สามารถระบุตัวบุคคลได้ และลบข้อความอิสระที่อาจระบุตัวบุคคลได้ ตามขั้นตอนของมหาวิทยาลัย โดยคงโครงสร้างรอบทุน เกณฑ์การประเมิน และคะแนนในเชิงสถิติไว้ ซึ่งครอบคลุมถึงข้อมูลสำรองด้วย ส่วนบัญชีผู้ใช้งานไม่ถูกลบตามข้อ 1.3.2.2 ประวัติการสมัครรายนักศึกษาตามข้อ 1.3.2.13 นับระยะเวลาแยกรายรอบทุน และรอบทุนที่ถูกทำให้ไม่ระบุตัวตนแล้วจะไม่แสดงในประวัติ ส่วนประเภททุนเป็นข้อมูลหลักที่ไม่ผูกกับตัวบุคคลจึงคงไว้  
* **การพัฒนาและทดสอบ:** ใช้ข้อมูลจำลองทั้งหมด ไม่ใช้ข้อมูลจริงของผู้สมัคร  
* **เซสชันและเหตุข้อมูลรั่วไหล:** เซสชันหมดเวลาตามนโยบายความมั่นคงปลอดภัยด้านสารสนเทศของมหาวิทยาลัย และกรณีเกิดเหตุข้อมูลรั่วไหลให้ดำเนินการตามขั้นตอนของมหาวิทยาลัย ซึ่งรวมถึงการแจ้งหน่วยงานที่กำกับตามที่กฎหมายกำหนด

### 1.3.4.11 ระบบสามารถประมวลผลข้อมูลสรุปสำหรับหน้าวิเคราะห์ข้อมูลได้

โดยระบบรวบรวมและคำนวณข้อมูลสรุปตามข้อ 1.3.2.15 จากข้อมูลผู้สมัคร ผลการประเมินสถานะ Submitted (ผลการประเมินสถานะ Draft ไม่ถูกนำมาคำนวณคะแนน) และผลการจัดสรรทุนที่อยู่ในระบบ โดยแปลงคะแนนเป็นร้อยละของคะแนนเต็มของรอบทุนนั้นก่อนรวมหรือเปรียบเทียบข้ามรอบทุน ไม่นับผู้สมัครที่ไม่มีผลการประเมิน Submitted ในการคำนวณการกระจายและค่าสถิติของคะแนน ซ่อนค่าสถิติของกลุ่มที่มีผู้สมัครน้อยกว่าเกณฑ์ที่กำหนด และคำนวณจากข้อมูลที่ยังคงอยู่ตามระยะเวลาเก็บรักษาในข้อ 1.3.4.10 ทั้งนี้ ระบบคำนวณตัวชี้วัดเชิงสถิติดังนี้ (วิธีคำนวณและค่าอ้างอิงเป็นข้อเสนอ โปรดยืนยัน) (1) ดัชนีการแยกแยะของเกณฑ์ย่อย = ค่าเฉลี่ยคะแนนร้อยละของเกณฑ์ย่อยในกลุ่มผู้สมัครที่คะแนนสุดท้ายสูงสุด 30% ลบด้วยค่าเฉลี่ยในกลุ่มต่ำสุด 30% โดยไม่นับผู้สมัครที่ไม่มีผลการประเมิน Submitted และแปลผลอ้างอิงดังนี้ ต่ำกว่า 0 = ผิดปกติควรตรวจสอบ, 0 ถึง 0.09 = แยกแยะน้อยมาก, 0.10 ถึง 0.19 = น้อย, 0.20 ถึง 0.34 = ปานกลาง, ตั้งแต่ 0.35 = สูง (2) ค่าเบี่ยงเบนจากผู้ประเมินคนอื่นของผู้ประเมินแต่ละราย = ค่าเฉลี่ยของ (คะแนนรวมร้อยละที่ผู้ประเมินให้ผู้สมัคร ลบด้วยค่าเฉลี่ยคะแนนรวมร้อยละที่ผู้ประเมินคนอื่นให้ผู้สมัครคนเดียวกัน) เฉพาะผู้สมัครที่มีผู้ประเมินอย่างน้อย 2 ราย (3) ICC แบบ one-way random effects จากคะแนนรวมร้อยละของผู้ประเมินแต่ละราย เฉพาะผู้สมัครที่มีผลการประเมิน Submitted ตั้งแต่ 2 รายการ และแปลผลอ้างอิงดังนี้ ต่ำกว่า 0.50 = ต่ำ, 0.50 ถึง 0.74 = ปานกลาง, 0.75 ถึง 0.89 = ดี, ตั้งแต่ 0.90 = ดีมาก ตัวชี้วัดเหล่านี้ใช้แสดงผลเท่านั้น ไม่ปรับคะแนนสุดท้ายหรืออันดับ ซึ่งข้อมูลผลลัพธ์ประกอบด้วย

* ตัวกรองที่เลือก
* จำนวนและร้อยละตามกลุ่ม (คณะ ชั้นปี ช่วง GPA ประเภททุน)
* ค่าสถิติของคะแนน (ค่าเฉลี่ย มัธยฐาน ควอร์ไทล์ สูงสุด ต่ำสุด ส่วนเบี่ยงเบนมาตรฐาน)  
* ดัชนีการแยกแยะรายเกณฑ์ย่อย, ค่าเบี่ยงเบนจากผู้ประเมินคนอื่นรายผู้ประเมิน, ค่า ICC และระดับการแปลผล
* ข้อมูลสรุปผลการจัดสรรและแนวโน้มข้ามรอบ

## 1.3.5 ขอบเขตที่ไม่ครอบคลุมในโครงงาน

1. ไม่มีระบบรับสมัครทุนการศึกษา โดยการรับสมัครและการจัดเก็บข้อมูลผู้สมัครเกิดขึ้นในระบบทุนการศึกษาเดิม  
2. ผู้สมัครทุนการศึกษาไม่ได้เป็นผู้ใช้งานระบบ SEMS  
3. ไม่มีการให้ผู้สมัครแก้ไขข้อมูลส่วนตัวหรือข้อมูลการสมัครผ่านระบบ SEMS  
4. ไม่มีการกำหนดผู้ประเมินให้กับผู้สมัครเป็นรายบุคคลหรือจำกัดจำนวนผู้ประเมินสูงสุดต่อผู้สมัคร โดยผู้ประเมินคนใดก็ได้สามารถเลือกประเมินผู้สมัครรายใดก็ได้จากรายชื่อผู้สมัครในรอบทุนที่เปิดให้ประเมิน และไม่มีการจำกัดสิทธิ์ผู้ประเมินตามรอบทุน ผู้ประเมินทุกคนที่บัญชียังเปิดใช้งานอยู่เห็นผู้สมัครของทุกรอบทุนที่อยู่ในสถานะ Open  
5. ไม่รองรับการแก้ไขผลการประเมินที่มีสถานะ Submitted และไม่รองรับการยืนยันส่งผลการประเมินแทนผู้ประเมินโดยผู้ดูแลระบบ  
6. ไม่รองรับการแก้ไขข้อมูลหลักของรอบทุน ข้อมูลผู้สมัคร และเกณฑ์การประเมินที่ใช้ในรอบ หลังจากรอบทุนเปลี่ยนเป็นสถานะ Open  
7. ระบบไม่เป็นผู้ตัดสินใจอัตโนมัติว่าผู้สมัครรายใดได้รับทุนและได้รับทุนเป็นจำนวนเท่าใด โดยผลการจัดสรรเป็นการพิจารณาของคณะกรรมการ และระบบทำหน้าที่บันทึกและตรวจสอบผลการจัดสรร  
8. ไม่มีการดำเนินงานหลังจากการจัดสรรทุนและการส่งออกข้อมูลรายงาน เช่น การประกาศผล การโอนเงินทุนผ่าน Promptpay หรือการติดตามผลหลังได้รับทุน โดยเลขบัตรประชาชนที่ระบบแสดงและส่งออกใช้สำหรับเจ้าหน้าที่ดำเนินการโอนเงินนอกระบบ SEMS  
9. ไม่รองรับการลบข้อมูลรอบทุนการศึกษา เนื่องจากข้อมูลรอบทุนมีความสัมพันธ์กับข้อมูลผู้สมัคร ผลการประเมิน และผลการจัดสรรทุน  
10. ไม่รองรับการลบบัญชีผู้ใช้งาน สามารถปิดการใช้งานบัญชีได้เท่านั้น  
11. ไม่รองรับการแก้ไขข้อมูลผู้สมัครโดยตรงผ่านระบบ SEMS และไม่อนุญาตให้นำเข้าหรือแทนที่ข้อมูลผู้สมัครในรอบทุนที่เปิดแล้ว กรณีข้อมูลผิดพลาดในรอบที่ยังเป็น Draft ให้แก้ไขที่ระบบทุนการศึกษาเดิมแล้วนำเข้าไฟล์ใหม่ ซึ่งจะแทนที่ชุดข้อมูลผู้สมัครเดิมทั้งหมดของรอบทุนนั้น ส่วนกรณีพบข้อมูลผิดพลาดหลังเปิดรอบแล้ว ระบบไม่รองรับการแก้ไขหรือนำเข้าซ้ำ  
12. ไม่รองรับการส่งออกข้อมูลในรูปแบบ CSV โดยกำหนดขอบเขตการส่งออกเป็นไฟล์ Excel (.xlsx)  
13. ไม่มีแอปพลิเคชันบนโทรศัพท์มือถือโดยเฉพาะ โดยระบบพัฒนาเป็นเว็บแอปพลิเคชันที่รองรับการแสดงผลแบบ Responsive  
14. ไม่รองรับระบบแจ้งเตือน (Notification) และการส่งอีเมลแจ้งเตือนอัตโนมัติ  
15. ไม่มีหน้าจอสำหรับเจ้าของข้อมูลส่วนบุคคลในการใช้สิทธิตามกฎหมาย (ขอเข้าถึง แก้ไข ระงับการใช้ หรือลบข้อมูล) ใน SEMS โดยการใช้สิทธิดำเนินการตามขั้นตอนของมหาวิทยาลัยผ่านกองกฎหมายและเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) และการแจ้งวัตถุประสงค์การเก็บรวบรวมข้อมูลต่อผู้สมัครดำเนินการที่ระบบทุนการศึกษาเดิมและตามนโยบายคุ้มครองข้อมูลส่วนบุคคลของมหาวิทยาลัย  
16. ไม่มีฟังก์ชันลบหรือทำให้ข้อมูลไม่ระบุตัวตนตามระยะเวลาเก็บรักษา (6 ปี) ผ่านหน้าจอของ SEMS โดยดำเนินการโดยผู้ดูแลฐานข้อมูลนอกระบบ  
17. ไม่มีหน้าจอค้นดูบันทึกการใช้งาน (Audit Log) ใน SEMS โดยการตรวจสอบ Log ดำเนินการโดยผู้ดูแลระบบเซิร์ฟเวอร์นอกระบบ  
18. ไม่รองรับการตัดผู้สมัครออกจากการประเมินหรือการบันทึกการถอนตัวหรือไม่เข้าร่วมสัมภาษณ์ของผู้สมัครในระบบ SEMS โดยผู้สมัครที่ไม่มีผลการประเมินสถานะ Submitted เมื่อปิดรอบจะมีคะแนนสุดท้าย 0.00 และไม่สามารถได้รับการจัดสรรทุน  
19. ไม่มีการตรวจสอบความถูกต้องของเนื้อหาข้อมูลผู้สมัครเทียบกับระบบทุนการศึกษาเดิม ทั้งก่อนเปิดรอบและระหว่างการประเมิน (ระบบตรวจสอบเฉพาะรูปแบบตามข้อ 1.3.4.3) และไม่มีการตรวจสอบความถูกต้องของรายงานที่ส่งออกแล้ว
20. ไม่รวมประวัติการสมัครก่อนเริ่มใช้ระบบ SEMS และไม่เชื่อมประวัติกรณีนักศึกษามีรหัสนักศึกษาเปลี่ยนแปลง
21. ไม่มีการปรับคะแนน (Normalize) หรือเทียบอันดับรวมข้ามรอบทุนที่มีคะแนนเต็มต่างกัน ประวัติแสดงผลของแต่ละรอบแยกกัน
22. ผู้ประเมินดูประวัติการสมัครได้เฉพาะข้อมูลแบบจำกัดตามข้อ 1.3.3.3 (รอบทุน Closed ผลการได้รับทุนและจำนวนเงิน) ไม่รวมคะแนนสุดท้าย อันดับ และคะแนนหรือความคิดเห็นของผู้ประเมินรายอื่น
23. ไม่รองรับการลบประเภททุน สามารถปิดการใช้งานได้เท่านั้น
24. ประเภททุนใช้กำหนดเกณฑ์การประเมินเริ่มต้นของรอบทุนเท่านั้น ระบบไม่ตรวจสอบคุณสมบัติของผู้สมัครตามประเภททุน (เช่น GPA ขั้นต่ำ ชั้นปี) และไม่ตัดผู้สมัครออกจากการประเมินโดยอัตโนมัติ
25. หน้าวิเคราะห์ข้อมูลแสดงชุดการวิเคราะห์ตายตัวสำหรับผู้ดูแลระบบเท่านั้น ไม่รองรับการสร้างรายงานหรือกราฟตามที่ผู้ใช้กำหนดเอง การส่งออกหน้าวิเคราะห์ การพยากรณ์ผลหรือการแนะนำการจัดสรรทุนด้วยแบบจำลองทางสถิติหรือ AI
26. หน้าวิเคราะห์ข้อมูลไม่แสดงข้อมูลรายบุคคลของผู้สมัคร และไม่จัดอันดับหรือเปรียบเทียบคะแนนรวมข้ามรอบทุนที่มีคะแนนเต็มต่างกันนอกเหนือจากการแสดงเป็นร้อยละ
27. ผลวิเคราะห์ความสอดคล้องของผู้ประเมินและดัชนีการแยกแยะของเกณฑ์ย่อยใช้เพื่อแสดงผลเท่านั้น ระบบไม่ปรับคะแนน ไม่ถ่วงน้ำหนักผู้ประเมิน และไม่เปลี่ยนอันดับโดยอัตโนมัติ
