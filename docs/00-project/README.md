## 🔄 บันทึกการเปลี่ยนแปลงขอบเขต (Scope Version History)

### Version 4 (ปัจจุบัน) — ปรับปรุงตามข้อเสนอแนะอาจารย์ผู้ประเมิน
* **ประเภททุนการศึกษา (Scholarship Types):** เพิ่มการจัดการประเภททุนและกำหนดเกณฑ์ประเมินเริ่มต้น
* **คะแนนรวมเป้าหมาย (Flexible Target Score):** รองรับคะแนนเต็ม 1 – 1,000 คะแนน (เดิมบังคับ 100)
* **ประวัติการสมัครข้ามรอบ (Cross-Round Applicant History):** Admin ตรวจสอบประวัติเต็ม และ Evaluator ดูประวัติรอบ Closed แบบจำกัดสิทธิ์เพื่อป้องกันอคติ
* **หน้าสรุปข้อมูลวิเคราะห์ (Analytics Dashboard):** เพิ่ม 6 วิดเจ็ตวิเคราะห์ข้อมูลสถิติ ความเที่ยงตรงของผู้ประเมิน และแนวโน้ม
* **ขอบเขตที่ไม่ครอบคลุม (Out of Scope):** เพิ่มข้อกำหนดชัดเจนขึ้นเป็น 27 ข้อ เพื่อควบคุมขอบเขตโครงการ
