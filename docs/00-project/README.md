## 🔄 บันทึกการเปลี่ยนแปลงขอบเขต (Scope Version History)

### Version 4.1 (ปัจจุบัน) — ปรับปรุงความยืดหยุ่นในการจัดการรอบทุนและการนำเข้าข้อมูล
* **การลบรอบทุนสถานะแบบร่าง (Draft Round Deletion):** ปลดล็อกให้ผู้ดูแลระบบสามารถลบรอบทุนการศึกษาที่ยังไม่เปิดรอบ (สถานะ Draft) ได้ เพื่อความสะดวกในการจัดการรอบทุนที่สร้างผิดพลาด พร้อม Cascade ลบข้อมูลที่เกี่ยวข้องและบันทึก Audit Log (คงการล็อกห้ามลบรอบ Open/Closed เพื่อความถูกต้องของ Audit Trail)
* **โหมดการนำเข้าข้อมูลผู้สมัคร 2 รูปแบบ (Import Modes):** รองรับทั้งโหมด `Overwrite` (แทนที่ผู้สมัครเดิมทั้งหมด) และโหมด `Append` (คงข้อมูลเดิมไว้ และอัปเดตเฉพาะรายที่รหัสนักศึกษาซ้ำ)
* **การขยายขอบเขตข้อมูลนักศึกษา (Enhanced Data Validation):**
  * ขยายชั้นปีรองรับ 1–6 (เพื่อรองรับหลักสูตรการศึกษา 5–6 ปี เช่น สถาปัตยกรรมศาสตร์/แพทยศาสตร์)
  * รองรับเบอร์โทรศัพท์ 9–10 หลัก (เบอร์พื้นฐาน 9 หลัก หรือมือถือ 10 หลัก พร้อมระบบเติม 0 นำหน้าอัตโนมัติ)
* **การปกป้องข้อมูลส่วนบุคคลในข้อผิดพลาด (PDPA Masking):** ปิดบังเลขบัตรประชาชนเป็น `xxxx-xxxx-${4หลักท้าย}` ในการแจ้งเตือนข้อผิดพลาดรายแถว (Error Payload / Preview) ป้องกันการรั่วไหลของข้อมูลส่วนบุคคล
* **การป้องกันข้อมูลสูญหายในการประเมิน (Evaluator Auto-save & Guard):** ปรับปรุงการบันทึกคะแนนอัตโนมัติให้ Flush ข้อมูลทันทีเมื่อมีการสลับผู้สมัครหรือกดย้อนกลับ ป้องกันคะแนนตกหล่นจาก Debounce Delay

### Version 4 — ปรับปรุงตามข้อเสนอแนะอาจารย์ผู้ประเมิน
* **ประเภททุนการศึกษา (Scholarship Types):** เพิ่มการจัดการประเภททุนและกำหนดเกณฑ์ประเมินเริ่มต้น
* **คะแนนรวมเป้าหมาย (Flexible Target Score):** รองรับคะแนนเต็ม 1 – 1,000 คะแนน (เดิมบังคับ 100)
* **ประวัติการสมัครข้ามรอบ (Cross-Round Applicant History):** Admin ตรวจสอบประวัติเต็ม และ Evaluator ดูประวัติรอบ Closed แบบจำกัดสิทธิ์เพื่อป้องกันอคติ
* **หน้าสรุปข้อมูลวิเคราะห์ (Analytics Dashboard):** เพิ่ม 6 วิดเจ็ตวิเคราะห์ข้อมูลสถิติ ความเที่ยงตรงของผู้ประเมิน และแนวโน้ม
* **ขอบเขตที่ไม่ครอบคลุม (Out of Scope):** เพิ่มข้อกำหนดชัดเจนขึ้นเป็น 27 ข้อ เพื่อควบคุมขอบเขตโครงการ
