## 📋 ชุดสถานการณ์การทดสอบ (UAT Test Scenarios)

### ส่วนที่ 1: การทำงานของผู้ดูแลระบบ (Admin Scenarios)

| รหัส (ID) | สถานการณ์การทดสอบ (Scenario) | ขั้นตอนการปฏิบัติ (Test Steps) | ผลลัพธ์ที่คาดหวัง (Expected Results) | ผลการทดสอบ (Pass/Fail) | บันทึกข้อเสนอแนะ |
|:---:|---|---|---|:---:|---|
| **UAT-ADM-01** | การเข้าสู่ระบบด้วย KKU Account (Admin) | 1. เปิดหน้าระบบ SEMS-KKU<br>2. เลือกเข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ<br>3. ตรวจสอบการเข้าสู่หน้า Dashboard | - เข้าสู่ระบบได้สำเร็จ<br>- แสดง Dashboard และเมนูจัดการระบบของผู้ดูแลครบถ้วน | [ ] Pass<br>[ ] Fail | |
| **UAT-ADM-02** | การจัดการบัญชีผู้ประเมินทุน | 1. เข้าเมนู "ผู้ใช้งาน/ผู้ประเมิน"<br>2. กดปุ่ม "เพิ่มผู้ประเมิน"<br>3. กรอกข้อมูล กำหนดวันหมดอายุบัญชี และกดยืนยัน | - บัญชีผู้ประเมินถูกสร้างขึ้นในระบบ<br>- แสดงสถานะบัญชีและวันหมดอายุถูกต้อง | [ ] Pass<br>[ ] Fail | |
| **UAT-ADM-03** | การตั้งค่าชุดเกณฑ์การประเมิน | 1. เข้าเมนู "เกณฑ์การประเมิน"<br>2. สร้างชุดเกณฑ์ใหม่ กำหนดหัวข้อหลักและข้อย่อย<br>3. ตรวจสอบเงื่อนไขผลรวมคะแนน 100 เต็ม | - ระบบยอมรับเมื่อผลรวมเท่ากับ 100 คะแนนพอดี<br>- ระบบแจ้งเตือนหากผลรวมไม่เท่ากับ 100 คะแนน | [ ] Pass<br>[ ] Fail | |
| **UAT-ADM-04** | การสร้างรอบทุนและนำเข้าข้อมูลผู้สมัคร (Excel) | 1. สร้างรอบการประเมินทุนใหม่<br>2. นำเข้าไฟล์ Excel ข้อมูลผู้สมัคร (`.xlsx`)<br>3. ตรวจสอบการตรวจสอบข้อมูล (Validation) และจำนวนรายชื่อ | - ข้อมูลถูกนำเข้าครบถ้วนตามไฟล์<br>- แสดงจำนวนผู้สมัครถูกต้อง<br>- ข้อมูลส่วนบุคคล (เช่น เลขบัตร ปชช.) มีการ Masking | [ ] Pass<br>[ ] Fail | |
| **UAT-ADM-05** | การเปิดรอบการประเมิน (Open Round) | 1. ตรวจสอบความพร้อมของรอบทุน<br>2. กดปุ่ม "เปิดรอบการประเมิน (OPEN)" | - สถานะของรอบเปลี่ยนเป็น OPEN<br>- ผู้ประเมินสามารถเริ่มเห็นรายชื่อและทำคะแนนได้ | [ ] Pass<br>[ ] Fail | |
| **UAT-ADM-06** | การปิดรอบทุนและการจัดสรรทุน | 1. เมื่อการประเมินเสร็จสิ้น กดปุ่ม "ปิดรอบการประเมิน (CLOSED)"<br>2. ดูผลสรุปคะแนนและการจัดลำดับ (Ranking)<br>3. กำหนดจำนวนทุนและยืนยันการจัดสรร | - ระบบปิดรับการประเมินทันที<br>- คะแนนเฉลี่ยและการจัดอันดับถูกต้องตามเกณฑ์ Tie-breaker<br>- รายชื่อผู้ผ่านการจัดสรรถูกต้อง | [ ] Pass<br>[ ] Fail | |
| **UAT-ADM-07** | การส่งออกรายงานสรุปผลการจัดสรร | 1. เลือกปุ่ม "ส่งออกรายงาน (Export)"<br>2. เลือกรหัสผ่านป้องกันไฟล์ตามมาตรการ PDPA<br>3. ดาวน์โหลดไฟล์ Excel รายงานสรุป | - ได้ไฟล์รายงานสรุปผลที่มีการป้องกันด้วยรหัสผ่าน<br>- ข้อมูลในรายงานตรงกับผลสรุปในระบบ | [ ] Pass<br>[ ] Fail | |

### ส่วนที่ 2: การทำงานของคณะกรรมการผู้ประเมิน (Evaluator Scenarios)

| รหัส (ID) | สถานการณ์การทดสอบ (Scenario) | ขั้นตอนการปฏิบัติ (Test Steps) | ผลลัพธ์ที่คาดหวัง (Expected Results) | ผลการทดสอบ (Pass/Fail) | บันทึกข้อเสนอแนะ |
|:---:|---|---|---|:---:|---|
| **UAT-EVL-01** | การเข้าดูรายชื่อผู้สมัครที่ต้องประเมิน | 1. เข้าสู่ระบบด้วยบัญชีผู้ประเมิน<br>2. เปิดหน้ารายชื่อผู้สมัครในรอบทุนที่เปิดอยู่ | - เห็นเฉพาะข้อมูลที่จำเป็นต่อการประเมิน<br>- ไม่เห็นข้อมูลอ่อนไหว (PDPA) เช่น เลขบัตรประชาชนแบบเต็ม | [ ] Pass<br>[ ] Fail | |
| **UAT-EVL-02** | การบันทึกร่างคะแนนแบบอัตโนมัติ (Auto-save Draft) | 1. เปิดฟอร์มประเมินผู้สมัครคนที่ 1<br>2. กรอกคะแนนบางข้อ พร้อมพิมพ์ความเห็น<br>3. ออกจากหน้าจอแล้วกลับเข้ามาใหม่ | - ข้อมูลคะแนนและความเห็นที่กรอกค้างไว้ยังคงอยู่ครบถ้วน<br>- สถานะผู้สมัครแสดงเป็น "แบบร่าง (Draft)" | [ ] Pass<br>[ ] Fail | |
| **UAT-EVL-03** | การตรวจสอบความครบถ้วนก่อนส่ง (Validation Check) | 1. กรอกคะแนนไม่ครบทุกหัวข้อเกณฑ์บังคับ<br>2. กดปุ่ม "ยืนยันส่งผลการประเมิน" | - ระบบไม่อนุญาตให้ส่งผล<br>- แสดงจุดที่ยังกรอกไม่ครบอย่างชัดเจน | [ ] Pass<br>[ ] Fail | |
| **UAT-EVL-04** | การยืนยันส่งผลการประเมิน (Submit Evaluation) | 1. กรอกคะแนนครบทุกข้อ<br>2. ตรวจสอบคะแนนรวมในหน้า Preview<br>3. กดยืนยันส่งผลใน Modal Confirmation | - บันทึกผลสำเร็จ สถานะเปลี่ยนเป็น "ส่งแล้ว (Submitted)"<br>- ฟอร์มเปลี่ยนเป็นโหมดอ่านอย่างเดียว (Read-only) แก้ไขไม่ได้ | [ ] Pass<br>[ ] Fail | |
| **UAT-EVL-05** | การทดสอบความโปร่งใสแบบไม่เปิดเผยตัวตน (Peer-Blind) | 1. ผู้ประเมิน A ส่งผลคะแนนผู้สมัครคนที่ 1<br>2. ผู้ประเมิน B เข้าดูฟอร์มประเมินของผู้สมัครคนเดียวกัน | - ผู้ประเมิน B **ต้องไม่เห็น** คะแนนและความคิดเห็นที่ผู้ประเมิน A ได้ให้ไว้<br>- ฟอร์มของ B เป็นอิสระโดยสมบูรณ์ | [ ] Pass<br>[ ] Fail | |
