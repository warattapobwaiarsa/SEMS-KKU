# SEMS — Business Rules (BR)

**ฉบับ 1.2** — ปรับตามคำตอบรอบยืนยัน 14 ข้อ (แท็ก `[C#]`) และรอบที่ 2 หลังตรวจไฟล์ตัวอย่าง (แท็ก `[D#]`)

เอกสารนี้รวบรวมเฉพาะกฎทางธุรกิจ เพื่อใช้เป็นฐานในการเขียน Functional Requirement
ไม่รวมขั้นตอนการทำงาน (Flow) และไม่อ้างอิง Use Case

## วิธีอ่านเอกสาร

**รูปแบบรหัส:** `BR-<หมวด>-<ลำดับ>` เช่น BR-CRT-03

**คอลัมน์ "ที่มา"**

| แท็ก | ความหมาย |
|---|---|
| `[S x.x.x]` | มาจาก Scope (`ขอบเขตโครงการ - SEMS.md`) ข้อนั้น |
| `[Q#]` | มาจากคำตอบของคุณในรายการคำถาม ข้อที่ # |
| `[C#]` | มาจากคำตอบรอบยืนยัน (ข้อที่ # จากรายการประเด็นหัวข้อ 13 ฉบับ 1.0) |
| `[D#]` | มาจากคำตอบรอบที่ 2 (ข้อที่ # จากรายการประเด็นหัวข้อ 13.2 ฉบับ 1.1) |
| `[ASM]` | สมมติฐานที่ผมเติมเพื่อให้กฎสมบูรณ์ **ต้องยืนยัน** (ดูหัวข้อ 13) |

1. **คำอธิบายระดับคะแนน (rubric) ของเกณฑ์เดิม:** ชีต Criteria เดิมมีตัวเลือกระดับคะแนนพร้อมคำอธิบาย (เช่น 10/5/0) แต่ SEMS ตาม Scope กรอกจำนวนเต็ม 0–max และไม่มีที่เก็บคำอธิบาย Evaluator จะไม่เห็นเกณฑ์การให้คะแนน ต้องเลือกว่าจะใส่คำอธิบายไว้ในชื่อเกณฑ์ย่อย หรือถือเป็นนอกขอบเขต
2. **หัวข้อ "ดุลพินิจของอาจารย์ (0-10)":** ไฟล์เดิมระบุว่าระบุคะแนนอื่นได้ ซึ่งขัดกับกฎคะแนนเป็นจำนวนเต็ม 0–max (BR-EVL-03) ยังไม่ได้ตัดสิน
3. **Session 60 นาที:** ถ้า Evaluator สัมภาษณ์นานกว่า 60 นาทีโดยไม่แตะระบบ จะต้องเข้าสู่ระบบใหม่ (ข้อมูลที่ Auto-save แล้วยังอยู่) และต้องตรวจกับนโยบายมหาวิทยาลัยอีกครั้ง
4. **คอลัมน์ "ลำดับ" (BR-IMP-20):** ผมตีความ "ต้องอ่านลำดับด้วย" ว่าหมายถึงนำเข้าและเก็บค่าลำดับจากระบบเดิม ยังไม่ได้ระบุว่าจะใช้ทำอะไร (เช่น แสดงในหน้าจอ) หรือมีกรณีว่าง/ซ้ำอย่างไร ถ้าหมายถึงอย่างอื่นให้แจ้ง
5. **ลิงก์แผนที่ (BR-IMP-22):** เป็นการเพิ่มข้อมูลนอก Scope และเป็นตำแหน่งที่พักของผู้สมัครที่ Evaluator ทุกคนมองเห็น ควรตรวจกับนโยบาย PDPA ของมหาวิทยาลัย และขอให้ระบบเดิมใส่หัวคอลัมน์ให้ (ตอนนี้ระบุจากตำแหน่งคอลัมน์)
6. **รายการชื่อหัวคอลัมน์เทียบเท่า (ภาคผนวก A.1):** เป็นข้อเสนอจากไฟล์ตัวอย่างเท่านั้น ควรตรวจกับไฟล์จริงจากระบบเดิม
7. **เบอร์โทรบ้านและรูปแบบรหัสนักศึกษา:** เบอร์ 9 หลักที่ขึ้นต้นด้วย 0 (เบอร์บ้าน) จะไม่ผ่าน และรหัสนักศึกษาตรวจเพียงความไม่ซ้ำ (ตัวอย่างเป็นรูปแบบ `683040000-1`) ถ้าต้องการตรวจรูปแบบให้แจ้ง
